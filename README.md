# 📥 信息整合与 AI 分析平台

> 面向投资决策的信息整合 + AI 分析推荐 + 标的跟踪 + 政策时事聚合的轻量级平台。先底座后 AI，模块化单体架构。

## 📦 项目定位

把分散的多源金融信息（行情 / 财务 / 估值 / 公告 / 新闻 / 政策时事）收敛成统一标的详情视图，结合 AI 生成结构化简报与推荐，自选标的异动与重大事件实时推送，支持个性化主题订阅。

## 🛠️ 技术栈概要

- **后端**：Java 21 + Spring Boot 3 + MyBatis-Plus + SQLite(WAL) + Caffeine，`java -jar` 单包部署
- **前端**：React 18 + TypeScript + shadcn/ui
- **架构**：模块化单体 + DDD 分层（接口层/应用层/领域层/基础设施层，层内按业务域分包，单包部署、留未来拆服务缝）
- **LLM**：配置驱动多厂商接入（DeepSeek / GLM 等），运行时可切、支持 fallback，密钥走环境变量

后端 DDD 四层 × 业务域（见 [技术方案 §2 Container](/docs/02-设计/技术方案-信息整合平台.md)）：

| 层 | 职责 |
| --- | --- |
| 接口层 | Controller、参数校验、鉴权、统一响应 |
| 应用层 | 用例编排、事务边界，不写业务规则 |
| 领域层 | 实体/值对象/领域服务/业务规则，纯净不依赖框架 |
| 基础设施层 | Repository 实现、SourceAdapter、LlmGateway provider、缓存/限频/定时 |

业务域（层内分包）：aggregation 多源聚合 / ai LLM 网关+简报 / push 异动推送 / policy 政策时事 / subscription 订阅信息流 / common 横切。跨域协作走领域事件。

前端页面（侧栏导航 4 分组，共 13 页）：总览 = 概览仪表盘；数据 = 自选清单 / 标的详情 / 政策时事；分析 = AI 简报 / 个人信息流；运维 = 任务中心 / Job 日志 / 成本报表 / 模型配置 / 数据源配置 / 提示词模板。

## 🔐 环境变量（部署）

> LLM 模型参数（provider/模型/单价/预算/超时/缓存 TTL 等）与**数据源参数（端点 URL/字段列表/referer/条数/mock 模式/降级链等）均仅页面配置**（runtime_config DB 持久化，首启由代码内置缺省播种，ADR-0020/0032），不走环境变量与 application.yml；API key 环境变量仍为一等来源（页面写入 DB 密文后优先生效，ADR-0018）。数据源降级链热生效（ADR-0033）：`datasource.{QUOTE,VALUATION}.fallbackChain`（如 `["eastmoney","tencent"]`，首元素=主源，可换主源/清备选，页面「降级策略」区块可视化编辑）、A 股列表桶 `subject.sync.fallbackChain`（`["eastmoney","sina"]`）——保存后下一次取数即新链，无需重启；DB 无链配置时代码内置默认链兜底，旧 `backupSource`/`aShareSource` 单值键读取兼容折算（写路径统一 fallbackChain，ADR-0031/0032 语义完整保留）。

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `JWT_SECRET` | 是 | JWT 签名密钥（≥32 字节，缺失启动 fail-fast） |
| `CONFIG_SECRET` | 否 | 运行时配置中 **LLM API key 密文的主密钥**（AES-256-GCM，≥32 字节，ADR-0018）。配置后可在「模型配置」页录入/轮换各 provider 的 API key（加密落库、只写不回显）；**未配置不阻断启动**，key 写入接口返回 30064（503），页面降级为只读态「key 走环境变量」。注意：轮换 `CONFIG_SECRET` 会使已存密文不可解，需在页面重新录入 key |
| `DEEPSEEK_API_KEY` / `GLM_API_KEY` / `QWEN_API_KEY` / `KIMI_API_KEY` | 否 | 各 LLM provider 的环境变量 key（一等来源；页面写入 DB 密文后优先生效） |
