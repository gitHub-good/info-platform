### ⚖️ 拍板二 · 门户双专项期次裁决：格隆汇 / 腾讯双双推 M18

**格隆汇（Nuxt payload 专项）推 M18 批次三**，理由：

1. **边际价值低**：快讯品类已有 4 源冗余覆盖（金十/新浪 7×24/东财 7×24/同花顺），其独占价值 = 港美股快讯视角，而 V2.0 聚焦 A 股（蓝图 Won't：不建港美股体系，格隆汇仅补充视角源）。
2. **专项成本高且结构脆**：`__NUXT__` payload 解析专项（估 1~1.5 人天）+ 结构稳定性验证，且 Nuxt 站点改版即碎（普查已注记「结构稳定性落地期验证」）；M17 预算被行业深化三件与 GAP-03 必办挤压，容不下高成本低边际源。
3. **M18 更合适**：批次三 +8 源冲刺 30，池深度消耗大正需专项源撑数量，专项成本在 M18 的边际负担更小。

**腾讯资讯（端点定位专项）推 M18 预检窗口**，理由：

1. 普查置信最低（公开资讯端点未定位，两变体 API「方法未定义」/404）——探索型投入 payoff 不确定，不占确定性预算。
2. 平台维度不缺：腾讯 qt.gtimg 行情 V1 已接入（平台已计）。

### ⚖️ 拍板五 · 事件→行业影响链（定义 / 与推荐 P2 的区别与联系 / 承载 / 生成策略）

1. **定义**：单事件 → 多行业传导的**结构化影响评估**：受影响行业清单，每项 = 行业（∈ 申万 31 白名单）+ 方向（利好/利空/中性）+ 一句话逻辑 + 可展开完整逻辑链 + 依据回溯（事件原文引用 / event_item 结构化字段）。「降准 → 银行（利好：流动性宽松降低负债成本）/ 地产（利好：按揭利率下行预期）」即典型形态。
2. **与推荐 P2 关联的区别与联系**：
   - **区别**：P2（M16）回答「这事件**与我**有关吗」——事件 × 用户自选/订阅的**个人相关性判定**，输出 = 触发与推送，只做匹配不生成新事实；影响链回答「这事件对**行业格局**传导为什么」——事件 × 全行业的**市场传导分析**，输出 = 分析视图，生成 per 行业方向与逻辑（受白名单与回溯约束）。P2 服务降噪（越个人化越少推），影响链服务理解（越完整越有看头）。
   - **联系**：同源 `event_item` 结构化事实；影响链产出的 per 行业方向数据是 P2 行业命中的潜在增强输入——**v1 不改造 P2**（零回归红线），反哺消费列 M18 评估（Won't #16）。
3. **页面承载**：事件流页 `#/events` **事件详情扩展区块**（v1 不做独立视图）。理由：① 影响链是事件的属性展开，天然挂在事件上；② 独立视图需新入口/导航/空态，v1 高重要事件量级撑不起独立页；③ 蓝图 G 域 4 新页已锁定 M18 收口。「按行业反查传导链」独立视图列 M18 评估（Won't #15）。
4. **模板**：首批 **≥10 类**影响评估模板（蓝图口径）——8 类具名事件枚举全覆盖（业绩预告/并购重组/回购·增持·减持/重大合同·中标/政策发布/监管处罚·立案/高管变动/技术突破·产品发布）+ 政策发布宏观细分（货币/财税/产业等子类，「降准→银行/地产」即宏观政策传导典型；子类划分归架构对齐）。模板给出每类事件的默认传导框架，LLM 按事件具体内容在白名单内调整行业集与逻辑表述。
5. **生成策略**（结果语义，机制归架构）：**HIGH 事件落库后自动生成**（挂靠机制归架构，不阻塞管道 tick）；**MEDIUM 及以下按需生成**（用户首次展开事件详情影响链区块时触发）+ 生成后缓存留痕；LLM 失败/护栏降级态走**类型默认传导模板直出**（标注模板态，链路不死）。
6. **合规**：方向（利好/利空）是影响面描述非操作建议（沿 M16 卡片方向字段先例，A 股涨红跌绿惯例）；区块标注「AI 分析仅供参考」。

### ⚖️ 拍板六 · 走向判断 v1（规则 + AI 混合 / 置信度 / 合规红线）

1. **载体**：周报内固定区块（不做独立页、不做独立推送——蓝图裁决 3 三形态定位：走向判断是周报的组成部分，形态一热度榜 M15 已交付）。
2. **对象**：本周热度环比变化最显著行业，缺省 Top3 升温 + Top3 降温（可配）。
3. **混合机制**：**规则层产出信号**（近 2~4 周热度趋势方向与强度、事件密度周环比、政策动向计数——纯计算零 AI 成本）；**AI 层语言组织**（把信号组织为趋势性表述——零新增事实红线沿 M16 先例：判断必须锚定规则信号与结构化事件清单，行业/数字/方向以结构化输入为准，LLM 输出新增事实不采纳）。
4. **置信度**：高/中/低三档，由**规则层信号强度映射**（如连续 ≥2 周同向且事件密度超阈值 → 高），**AI 不可自行抬高或降低**；映射口径版本化留档（trend-v1，沿 heat-v1 / recscore-v1 / adopt-v1 先例）。
5. **输出形态**：每行业一条趋势性表述（升温/降温/持续高温等趋势语）+ 依据清单（热度快照序列与事件清单可点击回溯）+ 置信度。
6. **合规红线**（蓝图裁决 3 与 Won't 条款落地）：**不涉及个股买卖建议、不预测股价/点位**；只做行业信息面趋势描述；依据回溯与置信度为验收硬条款；页面标注「AI 分析仅供参考」。
