### 4.2 逐页全量对账（页间零重叠 + 排序 + 末页余数）

- **Recommendations**（65 条，size=20）：4 页收集 65 id 去重 65、id DESC 严格有序。

### 4.3 边界矩阵（三端点同测）

| 用例 | Events | Recommendations | Subscriptions |

### 4.4 筛选组合与 total 联动（API == SQL WHERE 复算）

- events `importance=HIGH` → total 10 == SQL `WHERE importance='HIGH'` 10；

- recommendations `level=P1` → total 1 == SQL `WHERE level='P1'` 1。

**结论**：三页分页对账全等，「页头共 N 条 == 分页 total == SQL 复算」三方一致口径成立（前端「共 N 条」与 total 同源断言在 Subscriptions.test:294 / Recommendations.test:341）。
