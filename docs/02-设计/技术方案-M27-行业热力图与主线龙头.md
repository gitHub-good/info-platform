## ⚖️ 3. 形态决策（ADR-0063 六项主裁决）

### 3.1 行业行情双通道：主 push2 板块（REQ 原案）+ 备腾讯板块排行（Spike-C 新证），轮级互切不换实现（裁决 1）

- **通道 A（主）**：`EastMoneyBoardQuoteClient` 拉 `fs=m:90+t:2`（fields：`f12,f14,f3,f62,f184,f104,f105,f106,f20`，单页 pz=100 一次拉完约 86 行）→ 每板块行经 `IndustryDirectory.swPrimaryOf` 归一申万（未收录板块**安全侧跳过 + WARN 计数**，沿 M21 先例；首跑全量值域比对补映射为纯常量热修）→ `BoardAggregator` 聚合出 31 行业行。满足 REQ 拍板二「下钻东财板块清单」验收面。
- **通道 B（备，Spike-C C-2b 实证）**：`TencentBoardRankClient` 拉 `getRank board_type=hy`（31 行 SW31 逐名相等，一次请求）→ 直接产出 31 行业行（含 5 日涨跌幅与领涨股）。**push2 失败（重试耗尽）当轮即切**，不设熔断计数——轮级切换成本 = 1 次请求。
- **否决「腾讯单通道」**（尽管实测最顺）：REQ 拍板一/二以东财板块为热力图数据面与下钻层，M21 映射资产是既定验收面（场景 2 板块明细 + 映射关系 + WARN 口径）；且 push2 封禁为间歇史（M7 恢复先例），主备结构两者兼得。
- **否决「仅 push2 单通道 + 失败沿用旧快照」**：当前正处封禁期，单通道意味着上线即降级态；REQ 风险表明示备选通道评估义务。
- 快照行 `source` 列留痕通道来源；下钻端点按当日行 source 分形态（A→板块明细；B→成分股+领涨股，成分涨跌取 `market_daily_snapshot.pct_change`）。

### 3.2 板块→行业聚合方式：市值加权主口径，等权回退；涨跌家数与主力净流入加法直聚（裁决 2）

`pct_day(I) = Σ_B(w_B · pct_day(B)) / Σ w_B`，权重 `w_B` = 板块总市值 `f20`（>0）：

- **推荐市值加权，理由**：① 与行业指数体感一致（大市值板块主导行业涨跌，等权会把「银行Ⅱ」单板块与「电子」7 板块等量齐观）；② 权重数据零额外请求（同 clist fields 加 f20）；③ 通道 B 的腾讯官方行业涨跌幅即市值加权口径，主备切换时数值连续性最好。
- **回退链**：f20 缺失/≤0 行占比 >20% → 该行业当轮等权（`agg_method=EQUAL`）；行业下全部板块行缺失 → 通道 B 直出（`TENCENT_DIRECT`）。`agg_method` 落行留痕，页面脚注可查。
- **否决涨跌家数比为主口径**：它是广度指标不是幅度指标（"57/122 家上涨"≠"平均涨 1.2%"），语义变味；降级为独立列 `up_count/down_count`（**加法可直接聚合**：Σ f104 / Σ f105，通道 B 取 `zgb` 两数）参与持续性判定与页面展示。
- 主力净流入 `main_net_flow` = Σ 板块 `f62`（元；通道 B `zljlr`×10⁴）。5 日涨跌幅见裁决 3 口径。

### 3.3 采集节奏：FIXED_DELAY 30min（15~60 可配）全天运行，收盘自然定格；5 日涨跌幅库内自算（裁决 3）

- **盘中 30min 一轮**（任务区间建议 15~30 取保守上界）：通道 A 单轮 1 请求（86 行一页）× 48 轮/交易日 = 48 请求/日，远低于 M7 日同步 86 页基线；通道 B 单轮 1 请求 16KB。SQLite 单写者与 34 源错峰由 JobExecutor 同 jobKey CAS 串行 + 写事务毫秒级保证（117 行 UPSERT）。
- **盘后定格不设独立 CRON**：FIXED_DELAY 持续运行，15:00 收盘后首轮即终值，非交易时段轮次 UPSERT 同值幂等；次日首轮自然写新日期行。页面"定格"语义 = 快照 quote_time 不再变化。
- **5 日涨跌幅不依赖源字段**（f109/f170 在 clist 板块语境未实证且 C-1 受阻）：通道 A 由本表历史**自算** `pct_d5 = [Π(1+pct_day(d)/100) − 1]×100`（近 5 个交易日，含当日实时行，交易日集 = 本表 distinct snapshot_date）；通道 B 取源 `zdf_d5`（`d5_src` 落 basis 留痕）。冷启动 <5 日历史 → 该维 NULL + 榜单该维降权标注（REQ 故事 2 场景 6 缺维降权语义）。**好处**：口径自持、零源依赖、与持续性判定同一数据面。

### 3.4 主线口径 mainline-v1：三维行业内百分位加权 + 持续性硬门槛（裁决 4）

全部输入为库内既有面（零 LLM、零外呼）：

```
P(I) 价格动量   = 0.5·pctile(pct_day) + 0.5·pctile(pct_d5)          # 31 行业内百分位
H(I) 资讯热度   = 0.5·pctile(heat_H24) + 0.3·pctile(heat_D7) + 0.2·pctile(delta_pct)
E(I) 事件密度   = pctile(Σ_{e∈近5交易日, I∈affected_industries} w(e))   # HIGH×2 / MEDIUM×1 / LOW×0
M(I) 主线分     = 0.40·P + 0.35·H + 0.25·E                            # 权重可配
门槛：近 5 交易日中 ≥2 日 [ pct_day 排名 ≤ topThirdRank(=10) ] ∨ [ 当日 heat_top H24 排名 ≤ 10 ]
      —— 价格侧历史 = 本表日行；热度侧历史 = industry_daily_report.heat_top（每日 31 行全量留存，实测确认）
输出：门槛通过者按 M 降序取 Top N（默认 5，可配 3~5）；不足则如实输出实有条数（不出空榜单）
```

- **持续性以硬门槛实现**（而非计低分）：REQ 故事 2 场景 3 的两个可观测断言（"单日脉冲不进 Top3" + "榜单可见持续性标注"）均由门槛 + `persistent_days` 展示列满足；分数中混入持续性会引入第二套权重语义，复杂度不成比例——记 ADR。
- 某维原始值全缺（如冷启动期 pct_d5）→ 该维整体置 50 中性分 + `dimension_missing` 留痕（batch funnel_stats），不空榜。
- **对照徽章**：每行附 `heat_rank`（当前 H24 排名）；价格排名 ≤3 且热度排名 >13 → `divergence=PRICE_HOT_HEAT_COLD`（中性事实标注，REQ 场景 5）。
- basis 串（沿 heat-v1/weight_basis 先例）：`mainline-v1:wp=0.40,wh=0.35,we=0.25;pw=0.5/0.5;hw=0.5/0.3/0.2;persist>=2/5;topN=5;d5=self|tencent;input=IMS:2026-09-28+HS:snapshotAt+EV:2026-09-23~28`——同输入重算零漂移（纯函数，M20 构造性保证）。

### 3.5 龙头口径 leader-v1：三维综合分，价格条件维纳入（C-2 证实），主力徽章 Job 顺带（裁决 5）

```
成员集 M(I)  = subject_master.industry = I（含 M21 双通道回填产物——路 C 边已物化于该列）
               ∪ IndustryAssociator 路 C 当日投影（内存并集，去重；与 F2 同源同纯函数）
候选过滤     = ST 排除（RiskFactor.isStName 语义，excluded.st 留痕）+ 停牌保留（价格维缺省 50 + flag）
```

- **价格条件维纳入**（REQ 拍板四条件因子裁决）：C-2 实测 12/12 批量可得且 `market_daily_snapshot.pct_change` 已在产落库，5 日自算零新源——条件成立，权重 0.15（主维主导、价值修正强于价格，防纯噪音登顶即 REQ 拍板四 3 的落点）。

```sql
-- V35__create_industry_mainline_tables.sql

-- ① 行业行情快照（板块行 + 申万行业聚合行两级同表；row_type 区分）
-- dim_name：BOARD 行 = 东财板块名（f14）；INDUSTRY 行 = 申万行业名。
-- UNIQUE(row_type, dim_name, snapshot_date)：盘中轮 UPSERT 当日行（幂等键 = 方案库 03 业务语义键），
--   跨日自然新增——每日 ~117 行（86 板块 + 31 行业），180d/365d retention（见 ④）。
-- pct_d5：通道 A 库内自算（近 5 交易日 pct_day 复利累计）/ 通道 B 源 zdf_d5 直给；冷启动 NULL。
-- source：eastmoney-push2 / tencent-rank（降级链留痕）；agg_method 见行注释。
CREATE TABLE industry_market_snapshot (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  row_type      TEXT    NOT NULL,              -- BOARD / INDUSTRY
  dim_name      TEXT    NOT NULL,              -- 板块名（BOARD）/ 申万行业名（INDUSTRY）
  industry      TEXT    NOT NULL,              -- 申万 31 枚举（BOARD 行 = swPrimaryOf(dim_name)；未收录板块不落行）
  snapshot_date TEXT    NOT NULL,              -- Asia/Shanghai yyyy-MM-dd（幂等锚）
  pct_day       REAL,                          -- 当日涨跌幅 %
  pct_d5        REAL,                          -- 5 日累计涨跌幅 %
  up_count      INTEGER,                       -- 上涨家数（f104 / Σ / zgb 前数）
  down_count    INTEGER,                       -- 下跌家数（f105 / Σ / zgb 后数）
  main_net_flow REAL,                          -- 主力净流入（元：f62 Σ / zljlr×10⁴）
  total_mv      REAL,                          -- 总市值（元：f20 / Σ / zsz×10⁴）
  leader_stock  TEXT,                          -- 领涨股 JSON {"code","name","pct"}（通道 B lzg；通道 A NULL）
  source        TEXT    NOT NULL,              -- eastmoney-push2 / tencent-rank
  agg_method    TEXT    NOT NULL DEFAULT 'NONE', -- CAP_WEIGHTED / EQUAL / TENCENT_DIRECT / NONE(板块行)
  quote_time    TEXT,                          -- 源时间戳（stale 判定 + 三方对账锚）
  created_at    TEXT    NOT NULL,
  updated_at    TEXT    NOT NULL,
  UNIQUE(row_type, dim_name, snapshot_date)
);
CREATE INDEX idx_ims_date ON industry_market_snapshot(snapshot_date, row_type);      -- 热力图当日 31 行 / 5 日窗
CREATE INDEX idx_ims_board_industry ON industry_market_snapshot(row_type, industry, snapshot_date); -- 下钻按行业取板块行

-- ② 主线榜单（版本化沿 market_top_rank 先例：同日重算/手动 version+1，读最大 version）
-- dim_detail：三维分解 JSON（各维 rank/score/raw 原始值——对账与展示共用）
-- leaders：龙一/二/三 JSON 数组（§4.4.3 契约，含主力徽章与依据回溯）
-- divergence：NONE / PRICE_HOT_HEAT_COLD（价格≤3 名且热度>13 名的中性背离标注，REQ 故事 2 场景 5）
CREATE TABLE industry_mainline (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  rank_date       TEXT    NOT NULL,
  version         INTEGER NOT NULL,
  rank_no         INTEGER NOT NULL,            -- 1~5
  industry        TEXT    NOT NULL,
  main_score      REAL    NOT NULL,
  dim_detail      TEXT    NOT NULL,            -- JSON {"price":{...},"heat":{...},"event":{...}}
  persistent_days INTEGER NOT NULL DEFAULT 0,  -- 近 5 交易日上榜天数（门槛 ≥2 可配）
  heat_rank       INTEGER,                     -- 对照徽章：当前 H24 排名
  divergence      TEXT    NOT NULL DEFAULT 'NONE',
  leaders         TEXT    NOT NULL DEFAULT '[]',
  basis           TEXT    NOT NULL,            -- mainline-v1:... 口径串（§3.4）
  computed_at     TEXT    NOT NULL,
  created_at      TEXT    NOT NULL,
  updated_at      TEXT    NOT NULL,
  UNIQUE(rank_date, version, rank_no),
  UNIQUE(rank_date, version, industry)
);
CREATE INDEX idx_iml_date_ver ON industry_mainline(rank_date DESC, version DESC);

-- ③ 主线批次（一版本一行：漏斗计数/缺维/排除/徽章失败留痕——验收与审计读优化，沿 market_top_batch）
CREATE TABLE industry_mainline_batch (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  rank_date      TEXT    NOT NULL,
  version        INTEGER NOT NULL,
  trigger_source TEXT    NOT NULL DEFAULT 'DAILY', -- DAILY / MANUAL

                                               --        "dimensionMissing":{...},"excluded":{...},"attentionFailures"}
  degraded       TINYINT NOT NULL DEFAULT 0,   -- 快照缺当日行等降级态
  degraded_reason TEXT,
  basis          TEXT    NOT NULL,
  created_at     TEXT    NOT NULL,
  updated_at     TEXT    NOT NULL,
  UNIQUE(rank_date, version)
);
```

### 4.4 龙头识别与主力代理（T244）

#### 4.4.1 成员集与候选
