### 2.2 定位差异三阵营

- **规则/因子阵营**（通达信、TipRanks、Danelfin、Zacks、Morningstar）：可解释、可全量、可日频重算——**离「全市场 Top N」最近的路线**。
- **LLM 对话/助手阵营**（问财、妙想、Wind Alice、AlphaSense、Kensho、BloombergGPT）：强在自然语言交互、多源内容理解、事件解读——**用户主动提问时才深析，不做全市场主动扫**。
- **服务重运营阵营**（九方智投、雪球/韭研公社生态）：靠持牌投顾人工 + IP 打包收费，或纯社区 UGC——**我们个人自用场景不适配**。

### 2.3 Top 3 关键发现

1. **没有任何公开产品对全市场做「LLM 逐股深度分析 + 准实时全量刷新」**——实时者不用 LLM（Trade Ideas 规则+ML、通达信公式），用 LLM 者不全量（问财/妙想/Wind Alice 均为查询触发）。全市场每日全量评分的唯一公开先例 Danelfin 用的是量化特征工程（900+ 指标），LLM 只出现在交互与解释层。业界隐含共识：**全量靠便宜算子，深析靠触发**（高置信）。
2. **「有价值标的」的业界主流解法是「多因子合成评分 + Top N 榜单」而非自然语言断言**：TipRanks 8 因子 1~10 分 + Perfect 10 榜单、Danelfin AI Score + 排名、Zacks 1~5 级。评分的「依据」= 因子分解（哪几维贡献了分数），自然语言只负责解释不负责决策（高置信）。
3. **依据可靠性的业界标配是「方法论公开 + 引用溯源 + 业绩验证 + 免责」四件套**：Wind Alice 数据查询附参考文献、AlphaSense 摘要带原文片段、Kensho 输出实体消解后的结构化上下文、TipRanks/Zacks/Danelfin/Morningstar 全部公开方法论页并公示长期 track record，所有 C 端产品带免责声明（高置信）。我们 trace-v1 已对齐第 2 件，其余三件是缺口。

## ❓ 3. 六个调研问题逐题结论

### Q1 市面上「多源聚合 + AI 标的推荐（Top N）」怎么做？

**业界事实**（二手，高置信）：三类做法——① 自然语言条件选股（问财/妙想：用户说条件，AI 翻译成数据库查询，实时返回命中列表）；② 多因子评分 + 榜单（TipRanks/Danelfin/Zacks：全市场每日打分排出 Top N，如 Perfect 10 榜单）；③ 实时信号扫描（Trade Ideas/通达信：盘中全市场规则扫描即时出候选）。B 端（Wind Alice/Kensho/AlphaSense）把 LLM 用在「检索、摘要、实体消解」等中间层，不直接产出荐股结论。

**我们的取舍建议**：平台已有 L0~L3 管道 + 事件→标的关联（≈③的事件侧 + ②的雏形），V2.2 应取 **②为主干（全市场评分 Top10）+ ①为交互（自然语言问询已有管道数据）**，事件扫描继续复用现有 7×24 流。纯对话式选股（①单做）无法满足「主动发现」诉求。

### Q2 「有价值 / 有突破」的评估维度业界怎么定义？

**业界事实**（二手，高置信）：无「突破」统一定义；最接近的公开口径是「多因子融合」，五维覆盖：
- **基本面变化**：Zacks 用 EPS 预估修正动量（上修先于股价上涨）、Morningstar 用 DCF 公允价值折价 + 护城河；
- **事件催化**：新闻情绪（TipRanks 因子之一）、财报超预期动量（Zacks）、异动原因解析（妙想 ETF 异动 AI 解析）；
- **技术面**：Danelfin 900+ 指标中技术簇、Trade Ideas 形态策略；
- **资金与机构动向**：TipRanks 内部人交易 + 对冲基金持仓变动两因子；
- **产业链 / 主题传导**：妙想产业链机会挖掘、韭研公社式题材逻辑（社区口径）。

**我们的取舍建议**：定义「价值分 = 事件催化强度 × 基本面边际变化 + 资金/机构印证 + 行业热度传导，减 风险项」——前三项我们管道已有原料（事件提取/热度/影响链），EPS 修正与内部人数据需评估可得的公开源（信息缺口 §5）。「有突破」先落为「事件催化 + 主题传导」双触发，不引入需付费的盈利预估库。

### Q3 推荐的「事实依据可靠性」业界怎么保证？

**业界事实**（二手，高置信）：四件套——① **方法论公开**（TipRanks/Zacks/Morningstar/Danelfin 均有公开 methodology 页）；② **逐条引用**（Wind Alice 参考文献、AlphaSense 原文片段、Kensho 实体消解数据直连）；③ **业绩/回测验证**（TipRanks 按 10 万专家 track record 加权、Zacks 公示 1988 年以来层级表现）；④ **免责声明**（全部 C 端产品标配，AI 输出标注「不构成投资建议」）。

**我们的取舍建议**：trace-v1（资讯→推荐溯源）已对齐②，是相对优势；V2.2 需补齐：评分方法论文档（①）、推荐历史命中率/事件兑现率统计（③，可基于现有推荐留痕数据回算）、页面免责文案（④）。置信度呈现建议学 Danelfin——评分分解到因子簇可查，而非黑盒分数。

### Q4 「准实时计算更新」业界口径？

**业界事实**（二手，高置信）：分层口径，无产品对「深度分析」做全市场准实时——
- **事件/行情信号层**：秒~分钟级（Trade Ideas tick 级扫描、通达信盘中预警、雪球/社区实时流）；
- **评分层**：盘后日频全量（TipRanks 每晚收盘后更新 Smart Score、Danelfin 每日刷新全部 AI Score）；
- **深度叙事层**：事件触发或用户按需（问财/妙想/Wind Alice 的问答与分析）。

**我们的取舍建议**：把用户诉求「准实时」翻译为可执行口径——**关键事件触发的分钟级增量重评（事件到达 → 关联标的 → 局部重算）+ 每日盘后全量重算兜底**；界面展示「评分时间戳 + 触发事件」，而非追求全市场分钟级刷新（业界无先例且成本不成立，推测标注：由 Q5 成本结构推断）。

### Q5 全市场扫描（5000+ 标的）的工程做法？

**业界事实**（二手证据 + 推断，中高置信）：公开可考的做法全部是**漏斗**——Trade Ideas 全市场实时扫描用的是规则/ML 策略而非生成式 LLM；Danelfin 全市场每日评分用的是 900+ 量化指标特征工程；社区开源实践（多智能体 LLM 选股系统、量化漏斗项目）也是「规则/因子粗筛 → LLM 精析候选集」。**未发现任何「LLM 逐股分析全市场」的产品先例**（推测：按单次深析数千 token × 5221 只 × 日更计，Token 成本与延迟均不可行，且业界无人这么做本身即是证据）。

**我们的取舍建议**：四层漏斗草案（详见 §4.3）——L1 量化因子快照全量（DB 内计算，5221 只，秒~分钟级）→ L2 粗筛（规则阈值 + 因子排序取 Top 5%~10%，约 250~500 只）→ L3 LLM 深析（复用现有 L2/L3 管道的事件与分类数据，取 Top 30~50 只逐股生成分析）→ L4 合成 Top10 榜单（排序 + 溯源 + 免责）。增量路径：事件到达只重评事件关联标的并按需挤入/挤出榜单。

### Q6 合规边界（投顾牌照 / 荐股限制）？

**业界事实**（二手，高置信，有判例）：
- 《证券法》口径：向投资者提供具体证券投资建议属于证券投资咨询业务，**须取得证监会业务许可**，否则构成非法荐股；
- **个人自用不违法**（律师解读口径：自己用 AI 工具分析股票合法），红线在「对外提供」：无资质收费荐股可触**非法经营罪**——判例：福州鼓楼法院 2024.11 通报无资质直播荐股获利 1200 余万元获刑；某网络大 V 荐股被证监会罚没 4394 万元（单一来源，中置信）；公安部 2025.3 公布 5 起非法经营证券业务典型案例（含直播变相荐股）；
- 2025.05 证监会等八部门《综合整治非法跨境证券期货基金经营活动实施方案》后，平台侧（小红书等）同步治理荐股内容；AI 荐股骗局（借 DeepSeek 等）已被监管与媒体点名。

**我们的取舍建议**（红线清单）：① 平台保持**个人自用**，不对公众提供服务、不收费、不代客决策；② 界面与报告落「数据整理与信息展示，不构成投资建议」免责文案；③ AI 生成内容不出现「必涨/保证收益」类确定性断言（参照 [合规预检-21财经AI条款.md](/docs/02-设计/合规预检-21财经AI条款.md) 的既有口径）；④ 若未来开源/分享，分享的是「管道与工具」而非「推荐结果」，推荐结果不出库。

### 4.1 业界做法适配性判定（个人自用场景）

| 多因子评分 + Top N 榜单（TipRanks/Danelfin 范式） | ✅ 强适配 | 5221 标的池已有；因子原料（事件/热度/影响链）管道已产出；DB 内计算成本低 |
| 事件驱动增量重评 | ✅ 强适配 | 7×24 事件流 + 事件→标的关联已就绪，是「准实时」的正确落法 |
| LLM 逐股深析（问财/妙想式） | ✅ 适配但仅限子集 | LLM 只吃漏斗精筛后的 30~50 只，成本可控、质量可检 |

### 4.2 建议的评估维度草案（供 PM 立项参考）

「标的价值分」五维（每维 0~100，加权合成，权重可配置）：

1. **事件催化强度**（主维）：近 N 日关联事件的数量 × 类型权重 × 时效衰减（利好并购/订单/政策 vs 利空警示），原料 = L2 事件提取 + trace 关联；
2. **基本面边际变化**：业绩预告/快报超预期、研报覆盖变化（标题情绪）、估值分位（行情源已有）；
3. **资金与机构印证**：龙虎榜/大宗/股东增减持（公告源结构化）+ 成交量价异动；
4. **行业热度传导**：所属行业热度分 + 影响链上下游传导（行业热度与影响链已有）；
5. **风险扣分项**：ST/退市风险警示、监管处罚事件、解禁临近、负面舆情密度。

「有突破」= 事件催化 + 行业传导双高且风险项低（对应业界「estimate revision + theme momentum」口径）。

### 4.3 漏斗架构草案（业界对标：Danelfin 全量日评 + Trade Ideas 触发扫描 + Kensho 结构化上下文）

```
[7x24 资讯/公告流]                [标的池 5221 只]
      |                                  |
      v                                  v
 L0-L1 清洗/去重  ----关联---->  L1 因子快照层（DB 内计算, 日频全量+事件增量）
      |                                  |
      v                                  v
 L2 事件提取/分类/热度        L2 粗筛层（规则阈值+因子排序, 5221 -> ~300）
      |                                  |
      +---------- 关联映射 ---------->   v
                                    L3 LLM 深析层（~300 -> 30~50, 复用现有 L2/L3 管道输出）
                                           |
                                           v
                                    L4 Top10 合成（排序+评分分解+trace 溯源+免责）
                                           |
                                           v
                                    用户查看 -> 加自选（现有自选清单能力）
```

更新节奏：事件触发分钟级局部重算（关联标的）+ 每日盘后全量重算 + 每笔推荐落「评分分解快照」供命中率回算（Q3 第③件）。

### 4.4 给 PM 的 RICE 排序依据

- **Reach**：从「自选池关注触发型推荐（数十只）」扩到「全市场 5221 标的主动发现」，覆盖面扩大两个数量级（平台唯一用户 = 个人，Reach 上限即全标的池）。
- **Impact（价值强度依据）**：业界对照显示「全市场 Top N 主动推荐」是 C 端 AI 投研产品的核心付费功能（九方 29800 元/年档、TipRanks/Danelfin 订阅制），对个人用户的边际价值 = 消除盯盘盲区 + 机会发现前置；建议 Impact 评为高档。
- **Confidence**：中高——管道基础已就绪（事件/热度/溯源），缺口集中在「因子快照层 + 粗筛规则 + Top10 合成」，均为存量技术的重组；LLM 全量准实时已被业界证伪，不做反而降低风险。
- **Effort**：中等（预估 2~3 个里程碑量级，具体拆解归架构师）。
