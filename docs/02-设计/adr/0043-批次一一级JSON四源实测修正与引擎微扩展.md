# ADR-0043：批次一一级 JSON 四源实测修正与引擎微扩展两则

- 状态：已接受（2026-09-25，V2.0-M14 批次一 T110 实现偏差留档）
- 日期：2026-09-25
- 决策人：开发工程师（依据[REQ-20260925-11](/docs/01-需求/REQ-20260925-11-M14-批次一源接入与抓取大盘.md) T110「若引擎能力不够则最小扩展」授权与 ADR-0042「先实测再写映射」模式）
- 关联：ADR-0038（info_source 注册表）、ADR-0039（news_item 去重）、ADR-0042（试点源实测修正先例）、[V2.0 信息平台普查报告](/docs/02-设计/V2.0-信息平台普查报告.md) §2.1/§2.4/§2.5（四源普查样本）

## 📌 背景

T110 四源预检实测（每端点 curl 一次 + robots 复核）发现普查样本与当日实测存在四处差异/能力缺口：

1. **东财 7×24 参数演进**：np-weblist `getFastNewsList` 实测必带 `client=web&req_trace`（缺参 400 且报参数名），与普查样本（仅 `biz=web_724`）相比有参数演进；条目无直链字段。
2. **同花顺编码判定**：普查注记「today_list GBK」系 **HTML 通道**；实测 `tapp/news/push/stock` JSON 通道为 UTF-8（`application/json` 无 charset，Spring `StringHttpMessageConverter` 对无 charset 的 JSON 按 UTF-8 解码——与 Jackson 默认一致）。
3. **澎湃频道密度与端点缺失**：rightSidebar 财经专属列表仅 2 条（~5%，PM 待澄清 ② 触发）；同平台频道端点补位尝试 `nodeCont/254`、`nodeCont/25438`（数据实测观察到的财经 nodeId）、`wwwIndex` 均 404——平台无公开纯财经频道 JSON 端点。条目字段：`contId` / `name` / `pubTimeLong`（Unix **毫秒**，引擎只有秒转换）；无直链字段。
4. **东财宏观序列语义**：datacenter 默认序**最旧在前**（首屏 2013 年），须显式 `sortColumns=REPORT_DATE&sortTypes=-1`（排序列名 `DATE` 报 9501「排序列不存在」——普查「去掉错误排序列后即正常」注记的实测定位）；行数据为指标序列（多列数值），通用 `itemMapping` 无法组合出有语义的标题。

## 🎯 决策

- **引擎微扩展两则**（方案 §4.3 config 契约增字段，白名单与校验器同步）：
  - transform `epoch_millis_to_iso`（Unix 毫秒 → ISO-8601）：澎湃 `pubTimeLong` 口径；秒/毫秒两 transform 独立，误用有回归锚点用例。
  - `urlTemplate`（条目直链合成模板，占位符 `{externalId}`，须 http(s) 开头——校验器把关）：澎湃 `newsDetail_forward_{contId}` 公开规律；映射已产出 url 时不覆盖；东财 7×24 不配（源侧无网页详情可指）。
- **目录参数按实测对齐**：东财 7×24 端点落 `client=web&biz=web_724&fastColumn=102&pageSize=20&req_trace=1`。
- **澎湃按「要闻·含财经」定位接 `data.hotNews`**（20 条/轮，分钟级）：REQ 拍板一对澎湃的品类定位本就是「要闻·含财经」而非纯财经；纯财经频道端点同平台不可得（三端点 404 实测留档），密度不足留 PM/架构裁定（M17 纸媒补位候选）。
- **东财宏观走 preset 通道**（`EastmoneyMacroAdapter`，bean `eastmoneyMacroAdapter`）：序列→条目映射属代码语义（组合标题/摘要），不宜塞通用映射；报表字典常量首发仅 `RPT_ECONOMY_CPI`（唯一实测过的 reportName，ADR-0042「先实测再写映射」红线），PPI/PMI/社融扩行须先预检实测。**cursorType=NONE 裁量**：跨指标 TIME 游标会因期次日口径差异（CPI 月首 vs 其他指标月末）把后发布指标的当期条目误判已见——月度序列靠 (source_id, external_id) 唯一索引幂等（每轮全量 20 行重拉 OR IGNORE 吸收，24 轮/天量级可忽略）。
- **GBK 不做引擎扩展**：JSON 通道 UTF-8 实测 + 无 charset 解码行为有 MockRestServiceServer 单测锁定；普查 GBK 注记限定 today_list HTML 通道（本批不采用）。

## ⚖️ 被否方案与理由

- **澎湃换纸媒源补位（中证网/上证报）**：REQ 补位序「中证网→上证报」明确限定报纸类；JSON 类源同平台频道端点不可得不触发跨类补位，按品类定位降密度接入 + 回报 PM 裁定。
- **东财宏观 cursorType=TIME**：单报表可行，但字典扩行后跨报表期次日差异会产生漏抓（见上）；NONE+唯一索引在月度更新频度下成本可忽略，正确性优先。
- **东财宏观 json_api + 映射组合标题（如 title=TIME 值）**：标题只有期次无指标值（「2026年08月份」无信息量），不满足 REQ「条目标题/链接/发布时间字段完整」的字段语义。
- **urlTemplate 支持任意字段占位**：YAGNI——批次源只需 externalId（contId），白名单最小化校验面。

## 🔁 后果

- 既有六源映射与 M13 三源零影响（两扩展均为新增路径：transform 白名单加值、config 可选字段缺省关闭）。
- `SourceConfig` 构造签名 +1 参（urlTemplate 尾插）：编译期显式断裂，测试调用点机械补 null（本批已完成），无运行时漂移面。
- 目录新增四源 seed-if-absent：存量 DB 行不动；服务重启首启即播种（错峰 next_due_at），不重启不生效（当前运行中实例未含新源属预期，部署注记）。
- 澎湃 `newsDetail_forward_{contId}` URL 样式正确性未外呼验证（预检预算约束），T117 验收期点开首条条目复核；不对则 PATCH 目录常量（无需发版）。
- 后续源再遇「毫秒时刻/无直链」形态直接复用两扩展；「序列型数据源」复用 preset + 字典 + NONE 游标模式。
