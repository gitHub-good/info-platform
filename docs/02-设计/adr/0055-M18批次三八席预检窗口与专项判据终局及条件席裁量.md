## 📌 背景

T153 预检窗口（2026-09-26 执行，端点各 curl 一次 + robots 复核；格隆汇结构稳定性按判据加采两次同端点、腾讯端点定位双候选探测）覆盖：双专项判据（格隆汇四验/腾讯三验）、Nasdaq 恢复复核、纵深席候选、竞争席与条件席落位、六门户/媒体源现行结构、示例包可达性。

## 🎯 决策

**席位终局（9 新源，21 现役 + 9 = 30 精确命中）**：

| 席位 | 锁定 | 判据证据 |
| --- | --- | --- |
| 竞争席（第 8 席） | **格隆汇**（四验全过） | robots 404 无限制；`/live/` SSR `window.__NUXT__` payload 13 条快讯，title/route(直链)/createTimestamp(秒级) 三字段完整——时间戳经 Nuxt IIFE 参数绑定解析（`function(a..y){...}(args)` 尾参表，j..x 全部落在 epoch 秒实测 25/25 绑定可解）；试抓 13 条 ≥5；三次采样（间隔 6s）13/13 id 集合与结构完全一致 |
| 纵深席（第 7 席） | **东财·频道纵深 column=352**（np-weblist getNewsByColumns） | 与在役 em_headlines（column=350）同宿主同端点同构（code/showTime/title/url/summary，20 条带直链）——零新解析面；新浪滚动 feed.mix 候选亦可用（30 条）但需新宿主面，同宿主复用成本最低 |
| 条件席（第 9 席） | **中国经济网**（补位序第 2 位顶替） | Nasdaq 终局停用触发；补位序首位和讯 FAIL（news.hexun.com robots 与页面均返回同一 29180B 瑞数反爬 JS 挑战页，无服务端渲染窗口）；ce.cn robots 200 `Allow:/` 仅禁 /guanggao/（REQ 记 301 循环已落地失效），首页 SSR 182 带题锚点（滚动新闻 gdxw 41 条，URL 内嵌 `t{yyyymmdd}_{id}` 日粒度墙钟） |
| Nasdaq | **终局停用**（不恢复轮询） | 复核 curl http=000 超时（同 M17 BUG-M17-01 环境网络面证据，同通道 WSJ/MW 正常）→ 按 REQ 拍板二-3「仍不可达 → 停用软删 + 条件席补位」处置；软删执行归编排者（运行中服务不重启，本 ADR 只留结论），22→21 计数、目录行留档不删 |

**双专项判据结论**：

- **格隆汇：四验全过 → 占竞争席**（成本远低于 1 人天上限：payload 解析器为确定性文本变换——params 尾参表绑定 + 条目正则，无 JS 执行依赖）。
- **腾讯资讯：三验失败 → 永久关闭留档，不再复议**（沿 REQ 拍板二「定位失败即永久关闭」）：①端点定位——已知公开快讯端点 `i.news.qq.com/trpc.qqnews_web.kv_srv.kv_srv_http_proxy/list` 双候选探测（sub_srv_id=24hours/finance）均 `{"ret":0,"data":null}` 无结构化列表；②robots——news.qq.com/robots.txt 501 返回 WAF JS 盾挑战页（`waf.tencent.com` JS 跳转壳，非 robots 文件，与判据 1「无 JS 盾」冲突）；③试抓出数 0 条。关闭原因档案：端点无公开数据 + 宿主 JS 盾，腾讯平台维度已有 qt.gtimg 行情 V1 在役，非主线缺口。

**六门户/媒体源现行结构（通道修正三处）**：

1. **金融界**：REQ 记「列表路径」实测 `list/financenews.shtml` 404、`finance.jrj.com.cn` 与 `list/important_news.shtml` 均为小体量导航壳/静态精选（最新条目滞后 12 天）——现行 SSR 新鲜窗口为 **www 根首页**（81 条带题锚点，昨日新鲜度）；**合规注记落地**：www 根为无参数路径，robots（301 跟随 https 后 200）`User-agent: *` 仅禁搜索/翻页参数路径（`?page=`/`?keyword=`/`/search` 等），无参数根路径允许。
2. **央视财经**：jingji.cctv.com 首页为客户端渲染壳（仅 1 条 SSR 文章锚点），页面自身数据端点 `news.cctv.com/.../economy_zixun_1.jsonp` 公开返回（80 条/页，title/url/focus_date 秒级墙钟）——沿工信部检索 API 先例（ADR-0053）走 **json_api 通道**（stripPrefix=`economy_zixun(`、stripSuffix=`)`），非 REQ 预估的 preset HTML；news.cctv.com robots 404 错误页 → 无 robots 文件。
3. **新华财经**：cnfin.com 首页「新华快讯」块为唯一 SSR 新鲜窗口（15 条全带题，锚点文本内嵌 HH:mm 时分前缀 + URL 内嵌 `kx/detail/{yyyymmdd}/{id}_1.html` 日期 → 分钟精度墙钟），沿中证网 7×24 块先例。

其余三源与 REQ 预估一致：网易（money.163.com 首页 `/dy/article/{code}.html` 锚点 146 处/78 带题，无显式时间 → NONE 游标 + 摄取时刻回落）；凤凰（finance.ifeng.com 首页 74 条带题 `/c/{base62}` 锚点）；每经（www.nbd.com.cn 首页 `/articles/{yyyy-mm-dd}/{id}.html` 159 条唯一锚点，robots 200 仅禁 js/css/查询参数路径）。

**robots 判读汇总（2026-09-26 实测）**：163 200 全放行；ifeng 200 全放行（含 llms.txt 指引，聚合展示不涉）；jrj 301→https 200（参数路径禁、无参数根允许）；nbd 200（列表路径不涉禁项）；cnfin 301→https 200 全放行；jingji.cctv 302 跳错误页 → 沿人民网 302 先例按无限制；news.cctv 404 错误页 → 无 robots 文件；gelonghui 404；ce.cn 200 `Allow:/`；np-weblist 404（同宿主已档）；feed.mix.sina.com.cn 未复核（纵深席未选该候选，不留档义务）。

**示例包 ×2（默认停用，不计 30 口径）**：WSJ World News RSS（feeds.content.dowjones.io，200/72 条——M17 ADR-0053 曾以「时政密度」为由未入选正席，此处仅作默认停用模板复用其结构实证）+ IT之家 RSS（ithome.com/rss，200/60 条，境内可达异宿主，演示通用 RSS 通道非财经专属）；BBC Business 000 不可达、Investing.com 403 排除留档。

## ⚖️ 被否方案与理由

- **格隆汇走站点 XHR API 而非 `__NUXT__` payload**：快讯频道无公开文档化 API，探 API 端点属逆向未知接口（证监会红线先例）；SSR payload 是页面自身渲染产物、判据明示目标，四验在 1 人天内全过无悬念。
- **和讯降频/带 UA 绕过瑞数盾**：JS 盾绕过违背礼貌抓取红线（普查 §6），且瑞数为动态挑战无静态 UA 解；直接判 FAIL 走补位序。
- **腾讯继续探索其他端点（push/roll 等候选）**：0.5 人天上限内双候选探测均为空数据 + robots 501 JS 盾已构成「定位失败」判据证据；继续投入违背「成本上限即弃」。
- **Nasdaq 投专项排障**：REQ 拍板二-4 明示环境网络面不投排障成本（上限 0.5 人天即停用），国际面 WSJ+MW 双源兜底。
- **纵深席选新浪滚动 feed.mix**：结构可用但为全新宿主面（WAF/robots 均未实证）；东财 column=352 与在役源同宿主同构，四期实证基础设施直接复用，成本与风险双优。
- **示例包用 BBC/Investing**：境内不可达/403，用户启用即失败的示例是负资产。

## 🔁 后果

- 目录 22→31 预置行（+2 停用示例包 = 33 行）：nasdaq 行留档待编排者软删（21 现役口径）；9 新源适配六 preset HTML（网易/凤凰/金融界/每经/新华/中国经济网/格隆汇 payload）+ 二 json_api（央视 jsonp/东财 column=352）+ 格隆汇 preset（payload 解析器）——格隆汇适配器实现 Nuxt IIFE 绑定解析（params/args 表 + 条目抽取），fixture 单测零外呼。
- 格隆汇结构稳定性跨时段样本为同窗三次（间隔 6s），7 天观察期（周成功率 ≥95%）承载跨时段复核义务——判据 4 的「跨时段」维度由运行态补全，本窗口留档为同窗实证。
- 运行态验证（首轮出数/周成功率/同质独占率/疑似停更）归 T159 验收；同质对冲（门户/媒体 × 既有 22 源同稿）由跨源指纹去重前置拦截。
