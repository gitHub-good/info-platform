# ADR-0034：财务备选源新浪两页组合 + 公告备选源巨潮 cninfo——第四/第五降级链消费点（ADR-0031/0033 模式推广）

- 状态：已接受（2026-09-24，M8 财务/公告除单点）
- 日期：2026-09-24
- 决策人：架构设计师（2026-09-24 三候选 curl 实测 + 5 只标的与东财同报告期交叉核对；选型依据见[技术方案-财务源备选接入](/docs/02-设计/技术方案-财务源备选接入.md) §3 与附录）
- 补充：ADR-0031（备选源接入先例：client 输出东财中间结构 + adapter 组合）、ADR-0033（降级链模型：SourceProvider 枚举 + 注册表 + FallbackChainRunner）

## 📌 背景

财务/公告是 `SourceProviders` 注册表最后两个单 provider 源：2026-09-24 财务源 9501 事故（`uri(String)` 二次编码，f3cdcc1 修复）期间财务分区裸奔整回归窗口；ISSUE-A 实证东财财务/公告两端口同日 WAF 收紧，东财系故障时两分区大概率同挂。需求 REQ-20260924-05 要求：备选源最小完备集（报告期+营收+归母净利+ROE）齐备、**报告期口径（TTM-only 不合格）**、A 股全覆盖、限速友好；上线门槛为 5 只标的交叉核对（营收/净利 ≤1%、比率 ≤0.5pp）。

## 🎯 决策

### 1. 财务备选源 = 新浪 vFD 两页组合（`SinaFinanceClient`）

三候选实测（2026-09-24）：**腾讯不合格**（qt.gtimg.cn 行情串无营收/净利/ROE 字段；ifzq/proxy 无 F10 财务端点，`Can't load controller:FinanceReportController`）；**网易不合格**（quotes.money.163.com 全站 502，服务下线）；**新浪合格**：

- **两页组合**：`vFD_ProfitStatement`（报表日期/营收/归母净利，万元）+ `vFD_FinancialGuideLine`（加权净资产收益率/销售净利率/销售毛利率），`ctrl/{year}/displaytype/4`——两页分别缺营收绝对值/ROE，组合是新浪体系唯一最小完备集拼法；单页方案均不合格（被否）。
- **报告期口径**（硬性要求达标）：两页按报告期倒序列（2026-06-30/2026-03-31），与东财 F10 最新报告期累计同口径，非 TTM。
- **交叉核对 5/5 全达标**：600519/000001/300750/600036/601318 营收与归母净利相对偏差 **0.0000%**（万元舍入量级）、加权 ROE 与净利率偏差 **0.00pp**、报告期三源页全等（完整表见技术方案附录 A）。
- **行名变体**（client 正则/常量吸收）：营收「一、营业总收入」/「一、营业收入」（金融业）；归母净利「归属于母公司(所有者|股东)?的净利润」三种；ROE 取「加权净资产收益率(%)」（与 ROEJQ 数值一致；**禁用**摊薄口径「净资产收益率(%)」，茅台 17.72 vs 16.75）。
- **限速友好**：空 UA 200、8 连发全 200 稳定 ~0.17s、无 WAF、`charset=gbk` 显式声明；GBK 走 byte[] 显式解码 + Jsoup（GovPolicyClient/TencentQuoteClient 先例）。
- **年份回退**：当年 ctrl 无报告期行 → year-1 重拉一次（年初年报未披露窗口）；两页报告期错位以利润表为准对位取列。
- **主源港股沉淀**（T55 项提前完成）：东财 F10 对 00700 返回 `code:9201` 空体——主源本身不覆盖港股财务，备选（vFD 系 A 股页）对齐现状，不苛求。

### 2. 公告备选源 = 巨潮资讯 cninfo（`CninfoAnnounceClient`）——Should 确认纳入，不走变更控制出口

- 调研结论「有合格源」：`szse_stock.json` 实测含**沪深全量** 6258 条 orgId 映射（`sse_stock.json` 404 不需要）；`POST /new/hisAnnouncement/query` 双市场样本均可用、orgId 必填、时间倒序、无需 Referer；`announcementTime`（epoch ms=公告日）与东财 `notice_date` 完全一致（600519 半年报 2026-08-15）；详情 `static.cninfo.com.cn/{adjunctUrl}` 实测 200 application/pdf。
- orgId 映射 client 内缓存 24h（volatile + 双检同步刷新，刷新失败沿旧表）；`column_name` 无对应字段 → `category` 白名单语义缺失不产出（标题/时间/URL 与主源同形态）。
- 被否：交易所官方接口（上交所/深交所需分市场分端点分参数体系，接入面翻倍，cninfo 单端点双市场更优）；东财系内换端点（同族联动风险未除）。

### 3. 链接入（ADR-0033 复制，第四/第五消费点）

- `SourceProvider` +`CNINFO("cninfo","巨潮资讯")`（SINA 既有复用）；`SourceProviders`：FINANCE=`[eastmoney, sina]`、ANNOUNCE=`[eastmoney, cninfo]`——注册表全链即默认链，存量 DB 行 `fallbackChain` 缺省自动生效、显式编排不覆盖。
- `FinanceSourceAdapter`/`AnnounceSourceAdapter` 的 `doFetch` 改走 `FallbackChainRunner.fetch`（对齐 ValuationSourceAdapter 逐条抄）；FINANCE/ANNOUNCE 均无旧 `backupSource` 单值键历史，legacy 恒 null。备选 client 输出**东财中间结构**（新浪→F10 键、巨潮→flat 公告键），`eastmoney-finance.json`/`eastmoney-announce.json` 映射零改动。
- 弹性预算两轮合用 noRetry(2s)（东财快速失败 ~0.1s + 新浪两页 ~0.4s 预算内；巨潮稳态单请求）；挂起至超时兜底不保证为 ADR-0031 已知限制，接受；备选轮产物入既有缓存（1h/300s + 30s 负缓存）不放大限速压力。
- 可观测沿既有：降级 WARN（provider+链位）+ `RawFetch.source`「东方财富财务→新浪备选」/「东方财富公告→巨潮资讯备选」；三态与心跳签名不变。
- 前端：财务 `sina` 已在 `PROVIDER_LABELS`（零改动）；公告 `cninfo` 按需求许可补一条映射微调。

## ⚖️ 被否方案与理由

| 被否方案 | 理由 |
| --- | --- |
| 腾讯 qt.gtimg.cn 财务备选 | 行情串无营收/净利/ROE（最小字段集缺失，实测 52 字段清单）；ifzq 财务控制器不存在 |
| 网易 zycwzb CSV 备选 | 全站 502 服务下线（经典接口已死，3 次复测同果） |
| 新浪单页（仅 GuideLine / 仅利润表） | 分别缺营收绝对值 / 缺 ROE，最小完备集不齐 |
| 新浪 vFD_FinanceSummary（财务摘要单页） | 2018 年起数据下线，页面空壳 |
| 新浪 ROE 取「净资产收益率(%)」 | 摊薄口径（茅台 17.72），与东财 ROEJQ 加权口径（16.75）不一致——备选源首要目标是换源无感，按数值一致行映射（沿 ADR-0031 PE 52 位同款裁决） |
| 巨潮 orgId 缺省查询 / 硬编码映射表 | 实测无 orgId 返回空结果；硬编码 6258 条不可维护——运行时参数 + 24h 缓存 |
| 交易所官方公告接口 | 非不可用——双市场需两套端点参数体系，接入面翻倍；cninfo 单端点覆盖更优（「无聊但成熟」） |
| 财务备选两页失败产出半套数据 | 最小完备集完整性优先，宁 MISSING 不半套；两页任一失败=该级异常走链语义 |

## 💡 后果

- 财务/公告单点清除：东财系故障（封禁/WAF 收紧/9501 类空体）期间财务与公告分区自动兜底、恢复自动回归；降级链体系覆盖全部多 provider 化源，前端页面（一条映射除外）零改动。
- 兜底轮口径可信：5/5 样本全字段零偏差，远优于需求门槛；金融股新浪净利率/毛利率 '--' 缺失按需求许可降级展示。
- 净增 `SinaFinanceClient`/`CninfoAnnounceClient` 两 client + 两 adapter 链化改造 + 枚举/注册表/参数若干行；任务 T55~T58 合计 5.5 人天（Must 3.5）。
- 已知限制：东财挂起至超时兜底不保证（沿 ADR-0031）；新浪 vFD 为 HTML 接口，改版风险由「client 输出东财中间结构」的可替换性吸收；巨潮 query 偶发慢（1.97s 样本）同属预算限制。
