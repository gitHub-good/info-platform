# ADR-0058：M20 因子集与快照结构 / 权重模型 / 双 Spike 裁决（REQ-20260926-17 V2.2-M20）

- 状态：已接受（2026-09-22，M20 设计阶段）
- 日期：2026-09-22
- 决策人：架构设计师（蓝图 M20 段授权：快照表结构 / 评分引擎实现 / Spike-A 条件因子裁决归架构）
- 关联：[技术方案-V2.2-M20](../技术方案-V2.2-M20-因子快照与评分引擎.md)（§3 裁决全文 + §9 Spike 证据链）、ADR-0017（配置中心热生效）、ADR-0030/0031（push2 封禁前科与腾讯备选）、ADR-0046（管道四表）、[REQ-20260926-17](/docs/01-需求/REQ-20260926-17-V2.2-全市场智能标的推荐.md) 裁决 1/4

## 📌 背景

V2.2 M20 要为全市场 5221 标的建「因子快照层 + 评分引擎」：四维 Must 因子（事件催化/行业传导/基本面边际/风险扣分）加权合成分，权重页面化热生效、可复算幂等、权重版本入快照；估值分位与量价异动两个条件因子随 Spike-A 定夺；Spike-B 资金印证源预检留档。设计前核实的三个硬约束：① `subject_master.industry` 5221 只 **100% NULL** 且随新浪/东财源轮换覆盖漂移（ADR-0030）；② 行情批量快照未验证（push2 封禁前科）；③ 幂等语义被需求锁定（无输入变化重算结果不变）不可收窄。

## 🎯 决策（六项）

1. **快照形态 = 日频快照表**：`subject_factor_snapshot` 以 UNIQUE(subject_id, snapshot_date) 追加式落库、当日重跑同键覆盖（非最新态单表）——M21 榜单入出榜变动、M22 历史统计回算、「按当时权重复现」审计都要求历史序列。配套 `market_daily_snapshot`（行情估值日快照，UNIQUE 同构，F5 原料 + v2 时序分位序列资产）。迁移 V30/U30；M10 键空间扩两枚举（180d/365d，min 30/90）。
2. **行业传导绕行 subject_master.industry**：用 `IndustryAssociator` 从「事件 subjects 回联（affected_industries）+ news_analysis matched_subjects 回联（main/sub）」双路派生标的↔行业关联集（30 天窗、半衰期消退）。理由：行业字段当前全 NULL，且**随源轮换漂移的字段入因子会结构性破坏可复算幂等**（同一历史日重算结果取决于重算时刻的主数据快照）。关联空 → F2=0 + `NO_ASSOC_INDUSTRY` 标注不隐藏。
3. **因子分 = 绝对饱和映射纯函数，百分位仅展示层**：每维 0~100 由单主体函数产出（饱和/夹逼/tanh），窗口与衰减锚定 snapshot_date 而非当前时刻；全市场百分位在查询层对当日快照行临时计算，不入库不进合成。否决横截面百分位做因子分：它使任一标的分数依赖全集合，M22 增量重评无法局部重算，可解释性也差。**幂等口径**：五输入（事件窗/热度 62 行/关联派生/行情日快照/标的名录）+ 参数不变 → 输出不变；热度 30min 滚动属输入变化（同日重跑允许 F2 漂移，detail 落所用 heat 值可对账）。
4. **权重模型 = runtime_config 单键 `score.weight` + 参数指纹入快照**：五维权重/窗口/半衰期/K 常数/三标签阈值一钥全载，`ValuationConfigValidator` 校验（非法 30087 拦截原值保留），保存即热生效（ADR-0017 快照热读）。快照行落 `weight_basis` 指纹串（`vs-v1:w=…;win=…;hl=…;k=…;bt=…`）为复算审计锚。编辑面沿留痕窗口先例挂**任务中心 FACTOR_SNAPSHOT 编辑 Dialog**（零新页面，保 M21「第 20 页」序号叙事）。缺省权重 (0.40, 0.20, 0.20, 0.20, 0.00)。「有突破」= F1≥60 ∧ F2≥50 ∧ F4≥80（阈值可配）。
5. **Spike-A 裁决（实测 2026-09-22，证据方案 §9.1）**：腾讯 qt.gtimg 批量可行——**600 只/请求（URL 5399B）稳定、650+ 被拒；全轮 5221=9 请求×500ms 间隔 8.8s 零失败**；PE@52/PB@46 与东财 ADR-0031 交叉核对值完全一致；PE 填充率 76%（亏损空值）、PB 99.2%；**push2 单只 stock/get 至今空响应（封禁仍在），批量 ulist.np 可用**。据此：**估值水平维（F5）纳入 v1**——横截面口径（PE→PB 回退链、低估值得高分、缺数中性 50）全套交付（计算/落库/详情分解），**默认权重 0.00** 不进 v1 排序基线（不污染四维 Must 链），页面化可启用；时序分位待序列 ≥250 交易日 v1.x 升级（变更控制）。**量价异动维不纳入**（单日横截面噪声大、无均量基线），只随行情快照落原始值（换手/振幅/涨跌幅/量）。实现复用既有 `TencentQuoteClient.fetchQuotes`（50/块=105 请求 ≈40s，余量 12 倍），push2 ulist 留 v2 备选；行情段失败不阻塞四维（降级继续 + NO_MARKET_DATA）。
6. **Spike-B 留档（实测 2026-09-22，证据方案 §9.2）**：龙虎榜 `RPT_DAILYBILLBOARD_DETAILSNEW`、增减持 `RPT_SHARE_HOLDER_INCREASE`、EPS 一致预期 `RPT_WEB_RESPREDICT`（含 EPS1~4/覆盖机构数/目标价/INDUSTRY_BOARD）三源实测可用——v2 资金印证维与财务因子库的立项依据成立；大宗交易 6 个候选报表名全部 9501 未命中，需页面级抓包。本期零接入，结论留档供 v2 REQ。

**方案库采用清单**（先查货架再自研）：03 幂等（UNIQUE 语义键 + 纯函数重算）✅ / 08 定时任务（第 16 个 ManagedJob 收编）✅ / 09 对账（裁剪为 coverage 数量对账端点）✅ / 04 缓存 ❌（单行索引查询毫秒级，加缓存徒增一致性面）/ 12 异步任务 ❌（全轮 <2min 同步完成）。05/06/10/11 不涉。

## ⚖️ 候选方案对比（关键三项）

| 决策点 | 方案 A | 方案 B | 结论 |
| --- | --- | --- | --- |
| 快照形态 | 日频快照表（94 万行/180d） | 最新态覆盖单表（5221 行常驻） | ✅ A——M21 变动/M22 统计/复算审计都要序列；B 抹掉历史对照物 |
| 行业来源 | event/news 双路关联派生（库内自洽） | subject_master.industry 直读 / EPS 源行业板块回填 | ✅ 派生——行业列全 NULL 且随源轮换漂移；EPS 源行业回填留 v2（覆盖度未知） |
| F5 条件因子 | 纳入但默认权重 0（全套交付） | 全裁（不落库）或全纳入（默认权重>0） | ✅ 前者——Spike-A 已证数据面可行，裁掉浪费已验证能力；默认权重>0 则横截面弱口径污染基线，违背「首版口径稳定」 |
| 因子归一 | 绝对饱和映射（单主体纯函数） | 全市场横截面百分位 | ✅ 前者——增量重评局部性 + 可解释；百分位降级为展示层仍可查 |

## 💡 理由（选型五维度速过）

全案零新依赖零新组件（新表 ×2 + 纯函数 ×7 + 第 16 Job + 三端点），成熟度/运维成本满格；可替换性——因子公式全部参数化进 `score.weight`，权重/窗口/阈值换值不换码，v1.x 因子口径升级走「新 basis 串 + 变更控制」不改表结构；学习成本——沿 HeatCalculator/留痕窗口/任务中心三个既有先例，无新模式。

## ⚠️ 影响

- 正面：四维 Must 链零外部源依赖（行情失败照算）；权重热生效 + 指纹审计满足需求三条锁定语义；详情区块拿到可分解可下钻（eventId → 既有 trace-v1 链）的最小可见面；market_daily 序列从 M20 起自然积累，v2 时序分位零补数成本。
- 代价：两表 ~350MB 峰值存储（180d/365d 窗口滚动）；F1/F3 原料重叠（设计内，蓝图裁决 1 认可）；同日重跑 F2 随热度滚动漂移（口径已显式声明，非缺陷）。
- 跟进：① v1.x 时序分位升级（序列 ≥250 交易日）；② v2 资金印证/EPS 接入另立 REQ（Spike-B 三报表名为输入）；③ push2 ulist 备选与大宗交易抓包核实挂 v2；④ ST 判定 v2 可扩退市风险警示名单源。
