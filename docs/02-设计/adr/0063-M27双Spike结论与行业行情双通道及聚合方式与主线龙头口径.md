## 📌 背景

REQ-20260928-22 冻结 M27（A 股行业热力图→主线→龙头→基本面闭环 v1），把双 Spike 实测定为硬前置（T240/T241）并交架构五项裁量：行情采集通道与降级（push2 当前间歇封禁）、板块→申万聚合方式（市值加权/等权/涨跌家数比）、采集频率（建议盘中 15~30 分钟）、主线三维权重与持续性口径、龙头三维权重与价格条件因子去留。代码核实基线（2026-09-22）：迁移 V34 已被 M23 占用（本批 V35 起，任务书「V34 起」按仓库现状校准）；ManagedJob 16 个现役；`industry_daily_report.heat_top` 为每日 31 行 H24 全量留存（热度侧持续性历史数据完备）；`market_daily_snapshot.pct_change` 在产（腾讯 f170 映射）。实测环境：本会话 push2 族（主域/编号域/delay/http/https）40 分钟窗口 30+ 次尝试全 `Empty reply`（IP 级封禁期）；datacenter 与腾讯两域全通。

## 🎯 决策（六主裁决 + 五随批）

1. **行业行情双通道 = 主东财板块（push2 `fs=m:90+t:2`，REQ 原案）+ 备腾讯板块排行（`proxy.finance.qq.com getRank board_type=hy`，Spike-C 新实证），轮级互切不换实现**——通道 A 保留 REQ 拍板二的东财板块下钻与 M21 映射验收面；通道 B 实测恰 31 板块与申万一级**逐名相等**（含当日/5 日涨跌幅、主力净流入、涨跌家数、领涨股字段超集，单请求 16KB），push2 失败当轮即切（成本 = 1 请求），快照行 `source` 留痕、下钻端点按 source 分形态（A→板块明细 / B→成分股 + 领涨股）。否决腾讯单通道（弃 REQ 既定验收面）与 push2 单通道（当前封禁期上线即降级态，REQ 风险表明示备选评估义务）。
2. **聚合方式 = 市值加权主口径（权重 = 板块总市值 f20）→ 缺失占比 >20% 回退等权 → 通道 B 直出**，`agg_method` 落行留痕；涨跌家数（Σ f104/f105）与主力净流入（Σ f62）加法直聚为独立列，**不做主口径**（涨跌家数比是广度指标非幅度指标）。理由：市值加权与行业指数体感一致、权重零额外请求、与腾讯官方行业口径连续性最好（备切换数值不跳变）。
3. **采集节奏 = FIXED_DELAY 30min（15~60min 可配）全天运行，不设盘后独立 CRON**——收盘后首轮即终值（定格 = quote_time 不再变化），非交易时段轮次 UPSERT 同值幂等；**5 日涨跌幅不依赖源字段**：通道 A 由快照历史自算（近 5 交易日 pct_day 复利），通道 B 取源 `zdf_d5`（d5_src 落 basis），冷启动 <5 日历史置 NULL + 榜单缺维降权标注。频控依据：通道 A 单轮 1 请求 ×48/日 << M7 日同步 86 页基线；f109/f170 板块语境未实证（C-1 受阻）不冒险。
4. **主线口径 mainline-v1 = 三维行业内百分位加权 0.40(价格)/0.35(热度)/0.25(事件) + 持续性硬门槛**——价格维 0.5 当日 + 0.5 五日；热度维 0.5 H24 + 0.3 D7 + 0.2 环比；事件维 HIGH×2/MED×1 近 5 交易日加权计数百分位；**持续性 = 门槛而非计低分**（近 5 交易日 ≥2 日价格涨幅前 1/3 或热度榜前 10，价格历史 = 本快照日行、热度历史 = 日报 heat_top 31 行/日），不满足不得进 Top——REQ 场景「单日脉冲不进 Top3 + 持续性可见标注」两断言由门槛 + persistent_days 列满足，分数混入持续性会引入第二套权重语义。权重/阈值全量入 `runtime_config industry.mainline` 键热生效，basis 版本串随行留痕，纯函数同输入重算零漂移。
5. **龙头口径 leader-v1 = 0.50 资讯关注度（主维）+ 0.35 价值评分 + 0.15 价格动量（条件维纳入）**——Spike-C C-2 实测腾讯批量 12/12 返回当日涨跌幅且 `market_daily_snapshot.pct_change` 在产、5 日库内自算零新源，**条件成立纳入**（REQ 拍板四条件因子裁决的落地）；主维 = 近 7 日 matched_subjects 回联计数 + 事件关联加权（SQL 可复算）；成员集 = `subject_master.industry`（含 M21 回填物化）∪ 路 C 当日投影；ST 排除留痕（isStName 语义复用）、停牌价格维 50 中性 + flag；输出龙一/二/三 + 三维分解 + 依据回溯 + 免责逐卡。
6. **承载 = 两 Job（`INDUSTRY_MARKET_SNAPSHOT` 第 17 键 FIXED_DELAY + `INDUSTRY_MAINLINE` 第 18 键 CRON 18:30）+ `#/industry-mainline` 第 18 页 + 两配置键热生效**——18:30 排在 FACTOR 17:30 / MARKET_TOP 18:00 后错峰（独立 CRON 不依赖触发，沿 ADR-0059 裁决 7）；**Job 16→18**（对 REQ「16→17」的校准：T243 手动重算 + 任务中心可视 + 调度解耦三要求只有独立 Job 键可完整满足，并入 17 键会使手动触发放大为主行情重采，语义错位）。
7. **随批 · 主力关注度代理随主线 Job 顺带计算内嵌 leaders JSON**（否决请求期惰性 + 内存当日缓存）：≤15 只 × 2 报表 ≤30 请求/日集中盘后，页面零外呼零缓存失效面，对账可复核（datacenter count）；失败置 UNAVAILABLE 不阻塞（增强件非闭环件）。等价满足 REQ 成本护栏「当日一次」语义。
8. **随批 · Spike-D 正名**：利润表/资产负债表真名 = `RPT_DMSK_FN_INCOME` / `RPT_DMSK_FN_BALANCE`（`RPT_F10_FINANCE_GINCOME`/`GBALANCE` 备选），需求书 `RPT_DMSR_FN_MAIN`/`RPT_DMSR_FN_BALANCE` 均 9501 不存在——**v2 REQ 必须按正名立项**；股东人数 `RPT_HOLDERNUM_DET` 个股维 + 复合日期窗过滤均实证可用，龙虎榜/增减持复合过滤（`(SECURITY_CODE)(TRADE_DATE/NOTICE_DATE>=)`）实证可用。
9. **随批 · C-1 受阻承接 = 开发期首跑复核条款**（T242 验收项）：push2 字段核对（≥10 板块同值抽验）+ 板块枚举与 swPrimaryOf 127 值域全量比对留档，缺口纯常量热修（M21 先例）；未收录板块安全侧跳过 + WARN 计数。
10. **随批 · 热力图形态 = 31 格等分 CSS Grid**（否决 treemap：无市值面积语义诉求、等分稳定可测、768px 友好）；色轨走 format.ts 市场方向色轨单点导出（T229 规范，零状态色混用）。
11. **随批 · 榜单/龙头缺维语义 = 50 中性 + dimension_missing 留痕不出空榜**（冷启动期 pct_d5 / matched_subjects 历史稀疏两场景，REQ 故事 2 场景 6 的降权标注落地）。

## ⚖️ 候选方案对比（裁决 1 通道 / 裁决 2 聚合）

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 双通道主备（push2 主 + tencent 备） | REQ 验收面全保留；封禁期自动全量走 B 不停服；B 实测 SW31 直出字段超集 | 两客户端两解析器（+1 类成本） | ✅ 采用 |
| 腾讯单通道 | 实测最顺、免映射 | 弃 REQ 拍板二下钻东财板块与 M21 映射验收面；单源依赖 | ❌ |
| push2 单通道 + 失败沿用旧快照 | 类最少 | 当前封禁期 = 上线即降级态；REQ 风险表明示备选评估义务 | ❌ |
| 聚合·市值加权 | 指数体感一致；权重零额外请求；与通道 B 口径连续 | 依赖 f20 可得性（首跑复核） | ✅ 主口径 |
| 聚合·等权 | 零字段依赖 | 大小板块等量齐观（银行 1 板块 vs 电子 7 板块失真） | ✅ 回退口径 |
| 聚合·涨跌家数比 | 数据最稳 | 广度≠幅度，语义变味 | ❌ 主口径 / ✅ 独立列 + 持续性判据 |

## 💡 理由（五维度）

- **成熟度**：两通道均为已验证端点族（clist M7 在产 / qt 系 M20 在产 / datacenter M21 在产）；快照 UPSERT 幂等与版本化榜单 = M20/M21 两代生产先例。
- **社区/学习成本**：零新框架零新概念；双通道 = SubjectListSource 依赖倒置第三代复用。
- **可替换性**：`IndustryQuoteSource` 端口隔离源变化（换源只换实现类）；聚合口径 agg_method 落行可追溯可重算。
- **运维成本**：+2 Job 进任务中心既有治理面；48+1 请求/日频控裕量 30 倍+；retention 扩键三枚举复用 M10 体系。
- **风险面**：push2 封禁史被双通道结构性吸收（存续性不再单点依赖）；腾讯源改版有 31 名启动校验 fail-fast 防线；口径首跑校准有两配置键热生效 + basis 留痕回溯。

## ⚠️ 影响

- 正面：平台首个价格面行业数据层；「热力图→主线→龙头→基本面」闭环落地；M20/M21 资产（评分/映射/回联）在板块主线场景被消费；Spike-D 四端点证据为 v2 立项铺路（含 DMSK 正名纠错）。
- 负面/代价：+2 Job（16→18）与 +2 外部源依赖面；冷启动首周 5 日维/持续性门槛降级运行（basis 标注 warmup）；push2 字段契约待首跑实证（条款承接）；REQ 验收「16→17 Job」表述需测试侧同步校准为 16→18。
- 跟进：T242 首跑复核结论回填方案附录 A；主线口径首跑校准（权重/门槛）留痕；v2 REQ（股东人数/财务明细按 DMSK 正名/港股三前提）另立。
