# ADR-0062：V2.3 三轨合并形态与双轨退役方式及关联集读口三裁决

## 📌 背景

REQ-20260927-19 把 gov.cn 政策三轨（轨 A 六源 POLICY 按需拉取 / 轨 B policy_item 独立表双 Job / 轨 C 资讯源体系）收敛为单轨，交架构六点裁量：gov_policy adapter 形态与 GovPolicyClient 复用、source_url 去重迁移、policy-scope-v1 SQL 形态、行业关联集读口（直用 vs 落库快照）、contentId 新形态、旧路由重定向。代码核实基线（2026-09-22）：`FieldMapper.toIsoDatetime` 不支持 `yyyy-MM-dd` 纯日期（gov.cn DOCRELPUBTIME 即此格式，缺失 publishedAt 回落抓取时刻）；`GovPolicyClient` JSON 分支读 `datasource.POLICY` runtime_config 键（将冻结）；`PushType.POLICY` 零消费方；ManagedJob 18 个；news_item 4051 行 / 监管·政策容器 78 条；`SourceCode.POLICY` 枚举为编译期穷尽 switch。

## 🎯 决策（三主裁决 + 四随批）

1. **三轨合并形态 = gov_policy 纯目录配置（JSON_API 通道，零新 adapter 类）+ `FieldMapper.toIsoDatetime` 增纯日期分支（~6 行）+ policy-scope-v1 单 SQL OR 共用读口（`PolicyScopeQueryService` 一处、政策页/信息流/详情分区三消费面）**——否决桥接 GovPolicyClient（会延长将冻结的 `datasource.POLICY` 配置域寿命）与新写 PresetFeedAdapter（重复实现已验证解析）。source_url 去重迁移 = externalId 取 URL 落 `(source_id, external_id)` 唯一索引 + 跨源指纹（policy_item `existsBySourceUrl` 语义等价平移，ndrc_policy 同款先例）。单 SQL OR 否决两段 UNION：万行级内无实测收益、count+分页双查询 SQL 面翻倍（>10 万行预留切换注释）。
2. **双轨退役方式 = 代码整链删除（非种子 enabled=false 留壳）**——Job 面 18→16 需 JobRegistry 不再收编 bean（任务中心「不再出现两 Job」为验收场景）；删除面 = 两 Job / policy domain+infra 包 / GovPolicyClient+PolicySourceAdapter（含 INDUSTRY_KEYWORDS 字典）/ SourceCode.POLICY 枚举（穷尽 switch 编译期兜底全引用）/ 三处配置分支；V34 删 `job.POLICY_FETCH`/`job.POLICY_TENDENCY` 两键；`datasource.POLICY` 行保留冻结留档（零消费方，随 policy_item 纳入 M10 治理）；停跑留痕 = `job_execution_log` 历史行 + git 历史 + 本 ADR。随批：ai_tendency 由 L2 政策发布事件 direction 承接（PushType.POLICY 零消费方零改动）；contentId 新形态 = **`policy:news:{newsId}`**（`news:` 命名空间与历史 `policy:{policyId}` 数值域重叠零撞名，类型前缀保留 = 埋点语义延续；换代一次性、历史不回填）。
3. **行业关联集读口 = IndustryAssociator 直用（单标的即时现算）**——新 `SubjectIndustryAssociationReader` 复用 FactorSnapshotService 同形状三路窗口查询（SQL 侧 `LIKE '%:code%'` 裁剪）喂同一纯函数；否决快照落表（新表+新写路径+17:30 前口径漂移，为 5221 标的物化而消费方仅单标的按需查询）与直读 factor_detail JSON（非其契约字段，ADR-0061 裁决二同款否决理由）。同源性由构造保证 + 抽验复算用例锁定（本读口输出 vs 全量投影该标的关联集逐集相等）。
4. **随批 · `/api/v1/policies` 原地切换不升 v2**：唯一消费方同仓前端、同批发布（批内直接切换为 REQ 拍板一），换代留档于本 ADR；`?sourceCode` 显式选源时旁路 scope 口径（宏观源可显式选出数）。
5. **随批 · 旧路由重定向在路由归一层全局兜底**（`/datasource-config`→`/sources?tab=biz`、`/info-sources`→`/sources`，query 透传 + replace），散点改指为辅——漏改点自动被归一层捕获。
6. **随批 · 分区/政策页首版不加缓存**（毫秒级查询，方案库 04 预留：T207 观察 P95>200ms 再上 60s Cache-Aside）。

## ⚖️ 候选方案对比（裁决一接入形态 / 裁决三读口）

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 目录配置 JSON_API + 引擎日期分支 | 零新类；10+ 源同通道最成熟；治理全继承；旧 client 可干净删除 | 一处引擎扩展（通用收益非 gov.cn 特例） | ✅ 采用 |
| 桥接 GovPolicyClient 为 PresetFeedAdapter | 表面复用 | 延长将冻结配置域寿命；raw map 仍需映射；多一层间接 | ❌ |
| 新写 PresetFeedAdapter | 无历史耦合 | 重复实现已验证解析，代码量最大 | ❌ |
| 关联集即时现算（单标的投影） | 构造性同源；新鲜度锚定当下；零新表零 Job | 每次查看现算（毫秒级） | ✅ 采用 |
| 关联集快照落表 | 读 O(1) | 新写路径 + 日内口径漂移；按需单标的查询撑不起全量物化 | ❌ |
| 关联集直读 factor_detail | 零查询 | 非契约字段，污染下游解析 | ❌ |

## 💡 理由（五维度）

- **成熟度**：目录配置通道 = 33 源中 10+ 源两代迭代验证；IndustryAssociator = M20/M21/M22 三代复用纯函数；删除式退役 = 编译期穷尽性兜底的类型安全收敛。
- **社区/学习成本**：零新框架零新概念；引擎日期分支是既有白名单语义的自然延展。
- **可替换性**：policy-scope-v1 集中单读口，未来口径升 v2 只改一处；SQL OR→UNION 预留切换注释。
- **运维成本**：gov_policy 治理（启停/频控/连通性/大盘）零成本继承 SOURCE_POLL；删代码比留壳少一套「半死配置」审计面。
- **风险面**：分区兜底段与关联命中同库同查询面（仅少标的过滤）——MISSING 消除是构造性成立而非测试保证；contentId 命名空间隔离消除换代撞名风险。

## ⚠️ 影响

- 正面：gov.cn 单一抓取面；一条 LLM 轮询链路（ai_tendency）消失；政策条目进入分类/事件/热度/推荐全链路；Job 18→16 / 页面 20→19；详情分区从 2s 外呼预算变 <50ms 库内查询。
- 负面/代价：`policies` 契约原地切换要求 T201/T205 同批合入（单人自用可接受）；历史 `policy:{id}` 阅读留痕与新条目去重不复用（换代留档）；gov.cn JSON 改版时无 HTML 回退分支（按资讯源预检流程重接，非复活旧 client）。
- 跟进：分区三来源占比（标的关联/行业关联/宏观兜底）进 T207 观察留档，行业关联命中偏低则列 V2.3 后续调优；`datasource.POLICY` 行与 policy_item 表纳入 M10 生命周期治理处置。

## 🔍 后续验证方式

- Gate 1/2/3 断言用例随 T200/T201/T202/T203 交付（方案 §7 三闸门表）：口径对账（政策页 ⊆ 资讯库同条件且计数相等）、三类标的 MISSING=0 抽验、关联集同源复算、Job 面 16、policy_item 零新增、gov.cn 单一抓取面静态 + 留痕断言。
