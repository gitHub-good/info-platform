# ADR-0042：试点源实测字段口径修正与通用引擎容错三则

- 状态：已接受（2026-09-25，V2.0-M13 源接入框架 T106 实现偏差留档）
- 日期：2026-09-25
- 决策人：开发工程师（依据[技术方案-V2.0-M13](/docs/02-设计/技术方案-V2.0-M13-源接入框架.md) §3.4/§4.3/§4.6 与 T106「实测调参出数、偏差 PATCH 目录常量」授权）
- 关联：ADR-0038（info_source 注册表）、ADR-0039（news_item 与过滤规则）、ADR-0041（FetchResult 截断信号）、[V2.0 信息平台普查报告](/docs/02-设计/V2.0-信息平台普查报告.md) §2.2（试点源样本）

## 📌 背景

T106 三源真实外呼复核（各一次，robots 已普查合规）发现普查样本（2026-09-25 早间 curl）与当日实测存在三处字段/格式差异， 通用引擎按方案 §4.3 原样配置无法出数或整源被过滤清空：

1. **金十 `flash_newest.js` 包装空格漂移**：实测 `var newest = [...]`（`=` 两侧带空格），普查样本与方案 §4.3 示例为 `var newest=[...]`——精确 `stripPrefix` 前缀不命中，JSON 解析失败。
2. **金十条目字段嵌套**：正文位于 `data` 子对象（`data.title` 常为空、`data.content` 为正文），普查样本的顶层 `title` / `important_title` 字段不存在——原映射产出全空 title，整源被 §4.2「title 非空」过滤清空。
3. **新浪 7×24 字段名**：实测为 `rich_text`（HTML）/ `create_time`（`yyyy-MM-dd HH:mm:ss` 北京墙钟）/ `docurl`（详情直链），普查记 `richtext` / `ctime`（epoch 秒）——预置 adapter 按实测口径实现（本就归属代码适配，无需引擎改动）。

## 🎯 决策

- **FieldMapper 源字段点分导航**：`source` 含 `.` 时按嵌套 Map 逐级取值（任一级缺失/非 Map = 目标字段不产出，与顶层缺失同语义）；无 `.` 路径行为不变——既有六源映射零影响（其字段名均无点号）。
- **JsonApiFeedFetcher 标题回落**：映射后 title 空而 summary 非空时以 summary 补位标题（summary 置空）。快讯类 JSON 源「标题/正文分体且标题常空」是常态（金十中文快讯只有 content），不回落则整源被过滤清空。
- **包装剥离空白漂移容错**：精确 `stripPrefix` 未命中且 body 不以 `[`/`{` 开头时，回落「截取首个 `[` 或 `{`」（仅在声明了 stripPrefix 时启用）——任意 `var xxx =` 形态 JS 包装均可剥，空格漂移不再致解析失败。
- **目录常量按实测对齐**（T106 授权的 PATCH）：金十映射改 `data.title→title` / `data.content→summary`（strip_html）；新浪 adapter 按 `rich_text/create_time/docurl` 实现，目录 config（ID 游标）不变。
- 三源实测证据（各一次外呼，引擎链路端到端、不落库）：MW RSS 10 条/809ms；金十 50 条/228ms（中文快讯标题即 content 补位）；新浪 preset 20 条/205ms（rich_text 清洗 + docurl）。

## ⚖️ 被否方案与理由

- **金十走 preset 通道**（代码适配规避嵌套/回落）：该源是通用 JSON 引擎的试点本意（§3.4 验证目标），回退还意味着「嵌套字段源不能自增」——与「页面自增源 ≤10 分钟出数」目标冲突。
- **点分导航支持任意 JsonNode/数组下标**：YAGNI——试点与 M14 批次源无此形态，map 值即为 Jackson 转换的嵌套 Map，逐级 Map 足够。
- **标题回落放摄取层（FeedIngestService）**：过滤规则（§4.2）确在摄取层，但「title 语义缺失时以摘要补位」是 JSON 源映射语义的一部分（RSS 引擎无此形态——RSS title 恒有），归引擎映射层更内聚。

## 🔁 后果

- 既有六源 field-mapping 与聚合契约零变化（点分导航仅新路径激活；回归以 T102 既有测试 + 本次新增用例守护）。
- 金十目录行为 seed-if-absent 的存量行**不自动覆盖**（DB 为权威）——重启后需在源管理页 PATCH 或删行重种；本项目 DB 尚未播种生产流量，M13 上线首启即带新常量，无存量迁移面。
- 源端再漂移（如包装变量名变化）时：精确前缀 + 首边界截取已覆盖赋值类形态；结构性漂移由 FeedFetchException → 退避 + last_error 诊断 + 连通性测试复判兜底（§5 可观测）。
