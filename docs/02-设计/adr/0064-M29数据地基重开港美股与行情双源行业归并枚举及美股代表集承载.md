# ADR-0064：M29 数据地基重开港美股——行情双源与行业归并枚举及美股代表集与承载键

- 决策人：架构设计师

## 📌 背景

REQ-20260929-23 重开 M27 拍板一（港股 v2 条件复议、美股 Won't 三零）与 V2.0 蓝图 Won't「不建港美股体系」，重开方式 = 数据地基先行（池/行情/行业/资讯四件套 Must），功能层「地基落成即点亮」。REQ 交架构四项裁量：① 行情通道选型、② 港美股行业体系（硬边界 ≤40 枚举、可回填、与 L1 对齐）、③ 美股代表集构成、④ 新 Job 键编号与 V37+ 迁移清单。Spike-E（2026-09-29，本机 curl 实测）四件结论：datacenter F10 双报表全量+行业字段可得（港 6961 / 美 21561，push2 族仍 IP 封禁）；腾讯 qt.gtimg.cn 港美股批量行情可得（HK 78 字段布局与在产客户端一致、US 73 字段新布局）；板块级通道港美股不可得（腾讯 getRank 空集 + push2 封禁 + 恒生/GICS 付费）；资讯 = 东财 search-api 关键词（港美均 200）+ 新浪 roll lid=2516/2517（各 10 万滚动池）。代码基线（同日核实）：ManagedJob 19 键现役（NEWS_PULSE 第 19）；`industry_heat_snapshot` UNIQUE(industry, window_type)、`industry_market_snapshot` UNIQUE(row_type, dim_name, snapshot_date)、`industry_mainline(_batch)` / `market_top_rank(_batch)` UNIQUE(rank_date, version, …)——四组唯一键均无市场维，行业名跨市场可重名（如「银行」），分市场必须重建键；`IndustryCategory` 35 枚举代码侧白名单为 L1 校验权威；`Market` 枚举现 A_SHARE/HK/INDEX/SECTOR。

## 🎯 决策（四主裁决 + 五随批）

1. **港美股个股行情 = 腾讯主 + 新浪备双通道（轮级互切，沿 ADR-0031/0063 双通道结构），push2 不入港美股备链（封禁期 + 美股字段口径未实证，无「可用备链」资格，解封复核后升链尾）**——主通道 `qt.gtimg.cn`（Spike-E E-2a：HK 布局与在产 `TencentQuoteClient` 核对表一致零改动复用；US 新增第三套字段位分支：币种 @35 / 市值亿USD @44,45 / 时间戳美东 @30）；备通道新增 `SinaQuoteClient`（`rt_hk_` 实时前缀 + `gb_`，Spike-E E-2b：与腾讯同刻同值三字段交叉一致），产出与腾讯同款东财 f 键中间结构，adapter 层透明。**港美股行业行情 = 个股快照 × 行业就地聚合**（Spike-E §3.2 已裁：板块通道两源皆死，市值加权 → 缺失 >20% 回退等权，沿 ADR-0063 agg_method 语义），A 股 M27 双通道零改动。否决：东财 push2 港美股主通道（封禁期上线即降级态 + US secid 字段未实证）；否决新浪为主（美股 PE 口径 40.77 与腾讯 38.81 不一致、裸 `hk_` 前缀延迟 15 分钟需强制 `rt_hk_`，作主链风险面更大）。
2. **港美股行业体系 = 东财 F10 `BELONG_INDUSTRY` 中文口径直接落地，>40 时按「大类归并」收敛，映射表 `industry_enum_map(market, raw_name, enum_name)` 全量留档（回填率与归并口径可审计）**——港/美各自独立枚举集（各 ≤40，含 UNKNOWN 兜底位），**不映射回申万 31**（REQ 拍板二）；`IndustryCategory` 扩 `HK_INDUSTRIES` / `US_INDUSTRIES` 代码侧白名单（沿 ADR-0046「校验权威在代码侧」），首跑 F10 全量词频统计 → 枚举 ≤40 直接采用 / >40 由架构按东财行业大类归并（如「生命科学工具和服务→医疗健康」）T251 首跑后定稿回填方案附录。**L1 归类按条目市场注入枚举集**：`news_analysis` 加 `l1_market` 列（A_SHARE/HK/US，由 matched_subjects 主市场派生，无标的 → A_SHARE 容器面），prompt 仅注入该市场枚举集（调用次数与 prompt 长度近零增量）；容器 4 枚举跨市场共用；热度快照按 (l1_market, main_category) 聚合——跨市场重名行业（如「银行」）由 l1_market 消歧，`industry_heat_snapshot` 重建为 UNIQUE(industry, market, window_type)。否决：恒生/GICS 官方体系（付费无免费 API，Spike-E E-3b）；否决强制改名避开申万重名（造假口径，违反拍板二「不强行归一」）。
3. **建池规则：港股全量 + 美股代表集两步收敛**——港股 = F10 港报表 `SECUCODE` 5 位纯数字代码全量入池（~2600，行业 null → UNKNOWN 容忍，回填率可查）；美股 = 第一步宽集（后缀 ∈ `.N`(NYSE)/`.O`(NASDAQ) 主板过滤，剔除 `.F` OTC 样本已证行业恒 null）+ 第二步行情首轮后按市值收敛：`market_cap ≥ 20 亿USD`（runtime_config `subject.sync.us-mv-min-usd` 可配，覆盖罗素 3000 量级 ≈ ~3000 只；腾讯 US 布局市值 @44 亿USD，Spike-E 实证 AAPL 49356 亿 = 4.94T 与新浪 4938671029752 USD 交叉一致）保留 status=1，其余 status=0 留池行可查（不入采集与漏斗），日同步维护升降级。量级结论：港 2600 + 美 ~3000 = 5600 只，行情 50 只/请求 = 112 请求/轮。否决：美股全量 9000+ 入池（OTC 长尾僵尸股污染推荐漏斗与采集预算）；否决宽基成分指数固定名单（不可维护、漂移需人工跟）。
4. **承载 = 1 个新 Job 键 `HKUS_MARKET_SNAPSHOT`（第 20 键，FIXED_DELAY 60min〔30~120 可配〕）+ 既有六键扩维，V37 单迁移收口，19→20 Job**——新键一职三责：港美股个股批量快照（腾讯主/新浪备）→ `market_daily_snapshot`（UPSERT 幂等）+ 行业就地聚合 → `industry_market_snapshot(market='HK'/'US')` + 美股代表集市值收敛维护；60min 节奏 = 24 轮 × 112 请求 = 2688 请求/日（分块间 500ms 礼貌间隔，约 M7 日同步 86 页的 30 倍、腾讯 CDN 实测单轮 5600 只 8.8s 先例〔ADR-0058 Spike-A〕，频控裕量充足；收盘后轮次 UPSERT 同值幂等定格）。其余四件套全部扩既有键零新调度：SUBJECT_SYNC 扩 F10 桶、SOURCE_POLL/NEWS_PIPELINE 天然带新源、INDUSTRY_HEAT_SNAPSHOT/INDUSTRY_MAINLINE/MARKET_TOP_JOB/NEWS_PULSE 扩市场维。V37（+U37 回滚）单迁移：六表重建加 market 维（industry_heat_snapshot / industry_market_snapshot / industry_mainline / industry_mainline_batch / market_top_rank / market_top_batch，存量回填 'A_SHARE'）+ `news_analysis` 加 `l1_market` + `market_daily_snapshot` 加 `market_cap`/`currency` + 新表 `industry_enum_map`；`subject_master` 零 DDL（market 无 CHECK 约束、external_codes JSON 加键、UNKNOWN 口径纯应用层）。否决：每市场独立 Job 键（三键三调度面，收益零——采集轮内分市场串行即可）；否决并入市价快照既有 FACTOR_SNAPSHOT（17:30 CRON 时美股未开盘，时区语义错位）。
5. **随批 · 资讯四源两型接入（34→38）**：`sina-roll-hk`（lid=2516）/ `sina-roll-us`（lid=2517）为 json_api 配置型源（既有 roll 引擎零代码，沿 34 源同族）；`em-search-hk` / `em-search-us` 为 preset 型源（新 `EastmoneySearchNewsAdapter`：标的池 round-robin 游标轮询，keyword=名称，剥 `<em>` 清洗，Spike-E E-4a 三样本实证）——每市场恰 2 源满足 REQ F5；robots 三验补测列 T251 前置（Spike-E 证可达+结构，robots 未测，不达标即撤源走变更控制）。
6. **随批 · `marketOfCode` 显式化**：现实现「非 SH/SZ/HK 一律归美股」——INDEX/SECTOR 标的关联资讯会误入美股桶；改为四值显式（SH/SZ→A股、HK→港股、US→美股、其余→不计市场桶），行为变更留痕（现状误归面 = INDEX 4 只标的近零关联，回归可断言）。
7. **随批 · mainline-v1 市场化版本 = `mainline-v1:m2`**：三维权重/持续性门槛结构零变更，全部输入按市场切横截面（百分位市场内算、持续性序列按市场独立累积、bootstrap 沿 M27 先例）；港美股榜 `leaders` 恒 `[]` + `leader_unavailable_reason`（W1 占位不静默）。
8. **随批 · market-top 港美股价值维缺省留痕**：港美股漏斗 F3/F5 权重置 0 后**再归一**，`data_flags` 增 `NO_VALUATION_MARKET` / `NO_FUNDAMENTAL_MARKET`，funnel_stats.dimensionMissing 可查（沿 ADR-0059 维度裁剪留痕先例）；深析 +20 卡/日（HK 10 + US 10）全部走 cost-v2 scene-10 预算护栏（≤30% 触顶自动 FACTOR_ONLY，既有降级链零新机制）。
9. **随批 · LLM 增量护栏**：L1/L2/脉搏归纳调用次数零新增（条目驱动 + 枚举集按市场注入不增 prompt 面）；新增条目量 = 4 源 × 30~80 条/日 ≈ +15~30% 管道条目量，受 GuardLevel 三档降级既有护栏约束；热度/mainline/market-top 合成纯规则零 LLM（沿 M21/M27 基线）。

## 💡 理由（五维度）

- **成熟度**：datacenter / qt.gtimg.cn / hq.sinajs.cn / search-api / sina roll 五端点族全部 Spike-E 当日实证（200 结构化）；六表重建 = SQLite 标准改名重建法，V23/V30/V31 三代表先例。
- **社区/学习成本**：零新框架零新概念；F10 客户端仿在产 `EastmoneyDatacenterClient`，新浪行情客户端仿在产 `TencentQuoteClient`。
- **可替换性**：行情双源经 f 键中间结构对 adapter 透明（ADR-0031 结构复用）；行业枚举映射表化，换体系只改 `industry_enum_map` 与白名单常量。
- **运维成本**：+1 Job（19→20）进任务中心既有治理面；2688 请求/日 + 四源轮询进既有软限频/退避体系；retention 键空间零新增。
- **风险面**：push2 封禁被结构性隔离在港美股链外；行业词表 >40 由归并规则 + UNKNOWN 兜底双保险；美股盘中实时性未证由首跑复核条款承接（Spike-E §7 五项全部入 T251/T252 复核栏）。

## ⚠️ 影响

- 正面：港美股四件套地基全部落在实证可达端点上（零 push2 依赖）；五功能点亮全部为既有机制扩维（零新分析范式）；A 股链路结构性零触碰（新键新行新列 DEFAULT 'A_SHARE'）。
- 负面/代价：六表重建迁移（存量行回填，SQLite 锁表瞬间完成量级 ~万行）；+1 客户端 +1 adapter + 4 源依赖面；美股热力图 60min 粒度粗于 A 股 30min（v1 接受，可配）。
- 跟进：T251 首跑三件回填（F10 词频→枚举定稿、robots 三验、后缀分布）；T252 首跑两件（push2 解封补测、美股盘中实时性）；v2 另立 REQ（港美股财务因子/龙头复议/盘前盘后）。
