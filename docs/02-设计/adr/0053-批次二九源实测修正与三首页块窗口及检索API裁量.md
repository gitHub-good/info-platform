# ADR-0053：批次二九源实测修正与三首页块窗口及检索 API 裁量

- 状态：已接受（2026-09-22，V2.0-M17 批次二 T140~T142 实现偏差留档）
- 日期：2026-09-22
- 决策人：开发工程师（依据[REQ-20260926-14](/docs/01-需求/REQ-20260926-14-M17-批次二与行业深化.md) T140~T142「端点预检锁定/按现行站结构适配」授权与 ADR-0042/0043/0044「先实测再写适配」模式）
- 关联：ADR-0038（info_source 注册表）、ADR-0042/0043（实测修正先例）、ADR-0044（首页块窗口与 NONE 游标裁量）、[V2.0 信息平台普查报告](/docs/02-设计/V2.0-信息平台普查报告.md)

## 📌 背景

T140~T142 九源预检实测（端点各 curl 一次 + robots 复核；失败端点纠正性追测见下）发现与 REQ 锁定清单五处结构差异与两项通道裁量：

1. **工信部列表页客户端渲染**：REQ 记 `zwgk/zcwj` 新站结构，实测 `/zwgk/zcwj/index.html` 为 2KB JS 跳转壳（→ `wjfb/index.html` → `search/wjfb.html?...&category=51`），列表正文由站点公开检索 API `search-front-server/api/search/info` 客户端拉取（search.js 页面自身调用，参数 websiteid=110000000000000&searchid=51）。
2. **界面频道编号错记**：REQ 记 `lists/2` 实测为**商业**频道，财经频道为 `lists/800`（首页导航对照）。
3. **上证报现行入口为首页卡块**：旧 `news.cnstock.com` 子域 302 进新站 `/channel/*`（卡片客户端渲染）；`/list/10031`（上证智讯）为公告流、栏目列表页无日期——首页要闻卡块为唯一服务端渲染的新鲜窗口（沿 ADR-0044 证监会首页块先例）。
4. **中证网栏目列表 JS 模板渲染**：`/sylm/jsbd/list.html`、`/gppd/*/list.html` 等返回 `#title#` 占位模板——首页「中证快讯 7×24」块（`li > em{HH:mm} + a`）为唯一新鲜 SSR 窗口。
5. **人民网列表无显式时间**：`finance.people.com.cn` 频道首页 SSR 无日期展示，文章 URL 内嵌完整日期（`/n1/yyyy/mmdd/c{id}-{id}.html`）。

## 🎯 决策

- **九源全部接入**（预检全 200，无补位触发），目录 13→22 预置（REQ 累计源数口径，精确命中蓝图 ≥22 达标线），种子 seed-if-absent 补种（不重启不生效，部署注记沿 ADR-0043）。
- **工信部走 preset 检索 API 适配**（`MiitPolicyAdapter`，非 REQ 预估的 HTML 列表）：端点为页面自身公开调用的检索 API（与金十/澎湃/东财 np-weblist 同性质），非逆向未知接口（ADR-0044 证监会红线不涉）；响应 `data.searchResult.dataResults[].groupData[].data` 摊平（实测 groupData 均 1 条）、相对链接绝对化、`art_{uuid}` 作 externalId、`deploytime` 毫秒墙钟。
- **上证报/中证网/人民网走首页块窗口**（preset HTML 适配，沿证监会先例）：上证报 CSS-module 哈希类取前缀匹配（`a[class*=index_item]`）抗构建漂移；中证网发布时间 = URL 内嵌日期 + em 时分拼合（分钟精度）；人民网发布时间 = URL 内嵌日期（日粒度北京零点，沿发改委取舍）。
- **cursorType=NONE 七 HTML/检索源一致**（增量靠 (source_id, external_id) 唯一索引幂等吸收，裁量沿 ADR-0044）：工信部检索序非严格时间序（deploytime 1790038536069 先于 1790038626691 实测）；财政部/人民网 URL 日期仅日粒度；界面编辑序；上证报相对时间折算；中证网首页块无翻页。东财要闻沿同宿主快讯口径走 ID 游标（`code` 日期前缀数值）；国际 RSS 双源沿 MarketWatch TIME 游标先例。
- **频控落位**：官方（工信部/财政部）60min；东财要闻 15min（REQ 要闻频段下限）；纸媒三源 30min（REQ 频段上限）；人民网 60min = **Crawl-delay 120s 的 30 倍裕量**（REQ ≥15 倍条款）；Nasdaq 30min = Crawl-delay 30s 的 60 倍；WSJ 30min（MarketWatch 同族先例）。
- **externalId 口径**：工信部 art uuid 本体；财政部/界面/上证报/人民网 URL 数值段；中证网 `detail_{id}` 尾号（日期前缀天然携带）。

## ⚖️ 被否方案与理由

- **工信部 json_api 配置化接入**：groupData 中间数组无 List 下标导航语义（FieldMapper 点分仅 Map），须代码摊平——preset 通道正确。
- **中证网全首页 detail_ 锚点采集**：首页含 2026-07 旧文推荐位（日增噪音），限定 7×24 块（em 时分锚定）语义精确且密度达标（10 条/轮 ≥ REQ 5）。
- **WSJ World News 源**：结构可用（72 条）但时政密度高于市场线——选 RSSMarketsMain（61 条，市场要闻优先）。
- **Barron's 端点族**：`barrons_topstories`/`barrons_main` 均 404（候选名不存在的公开 feed）；Yahoo `rssindex` 403（拒绝）——双双排除留档，未走国内池补位（Nasdaq+WSJ 已锁定两席）。

## 🔁 后果

- 既有 13 预置源与业务域零影响（纯新增：五适配器 + 目录九行 + fixture 单测，存量配置字节级不变）。
- 预检留档（REQ 场景 7 必检项，2026-09-22 实测）：**robots**——miit 404 / cnstock 404 / cs.com.cn 404 / np-weblist 404（同宿主已档）→ 均「无 robots 文件 = 无限制」（RFC 9309）；szs.mof 302 跳主站 404 页 → 无 robots 文件（沿 csrc 302 先例）；jiemian 200 仅禁 Con 前缀路径（列表页不涉，REQ 注记复核一致）；**www.people.com.cn 200 全放行 + Crawl-delay 120s**（finance 子域 robots 404）→ 60min 间隔合规；nasdaq robots 200 通配放行 + Crawl-delay 30（/feed/ 不涉 Disallow）；feeds.content.dowjones.io 403 → 无 robots（MW T106 同族留档）。**可达性**：九源端点全 200 实证；WSJ RSSMarketsMain 首测连接重置、重试即 200（瞬时抖动非封禁）。**首轮出数**（实测截样本）：工信部 10、财政部 10、东财要闻 20、界面 4（fixture 截取；全量主列表约 10+）、上证报 10、中证网 10、人民网 12+、Nasdaq 15、WSJ 61——REQ 标定值（官方 ≥3、纸媒 ≥5、要闻 ≥10、RSS ≥5）全满足。**首条样本**：工信部《创新型产业集群建设管理办法》通知（2026-09-23）；财政部《境内单位代扣代缴自然人增值税管理办法》公告（2026-09-04）；东财「石沱长江大桥公路桥顺利合龙」（2026-09-26 11:45）；界面「伴随政策效果显现…宏观晚6点」（09-24 18:00）；上证报「苹果，逼近5万亿美元」（1 小时前）；中证网「大丰实业：中标约3.7亿元项目」（09-26 09:47）；人民网「高质量发展故事汇丨经略海洋」（09-24）；Nasdaq「The Case for Selling SpaceX Stock…」；WSJ「Stock Market News, Sept. 25, 2026…」。
- **工信部 WAF 风险**（普查预告）：预检未触发（UA+Referer 礼貌头 200 两轮）；运行期若触发走单源退避/静默降级（M13 基线），不阻塞其他源。
- 九源运行态验证（周成功率 ≥95%、同质独占率、疑似停更标记）归 T148 验收；同质对冲（上证报/中证网 × 证券时报同稿）由跨源指纹去重前置拦截。
