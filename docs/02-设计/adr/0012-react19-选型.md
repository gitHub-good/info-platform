# ADR-0012：前端 React 版本选型偏离基线（React 18 → 19）

- 状态：已接受（2026-09-21，T10）
- 日期：2026-09-21
- 决策人：架构师（依 T10 开发实测报告 + 知识库前端基线 frontend.md）
- 补充：ADR-0002（技术栈与存储，前端 React18+TS+shadcn/ui 表述）、知识库前端基线 frontend.md（React 18）

## 📌 背景

知识库前端基线 `frontend.md` 定「框架 | React 18（函数组件 + Hooks）」，ADR-0002 据此写「前端 React18+TS+shadcn/ui」。T10 标的详情页前端用 `npm create vite@latest` 起脚手架，最新 create-vite 模板默认装 **React 19.2.8**；同期工具链 Vite 8 / `@vitejs/plugin-react` 6 / shadcn/ui 最新版（Base UI 底座）的 peer 依赖要求 React 19。

约束：

- 不反向改知识库基线（基线是知识库级，变更走知识库自身流程，不在本项目范围）；项目偏离记本项目 ADR 即可。
- T10/T12 已实测：React 19 对所用 API（函数组件/Hooks/JSX）完全兼容，24 个前端测试全绿，生产构建 gzip 91KB。

## 🎯 决策

**接受 React 19，不 pin 回 18。** 项目前端使用 React 19.2.8，偏离知识库基线 React 18。

## ⚖️ 候选方案对比

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 接受 React 19 | 与最新工具链（Vite8/shadcn/Base UI）peer 一致；19 对所用 API 兼容；测试构建均绿 | 偏离知识库基线 18 | ✅ 采用 |
| pin 回 React 18 | 对齐知识库基线 | 与 Vite8/`@vitejs/plugin-react` 6/shadcn 最新版 peer 冲突，需降级整条工具链 | ❌ 否决，依赖冲突、得不偿失 |
| 等 React 18 LTS 维护结束再升 | 无 | 无必要（19 已稳定发布），推迟无收益 | ❌ 否决 |

## 💡 理由

T10 起脚手架时 `create-vite` 最新模板默认 React 19.2.8，Vite 8 / `@vitejs/plugin-react` 6 / shadcn/ui 最新版（Base UI 底座）peer 依赖要求 React 19，pin 回 18 会与最新工具链冲突，需降级整条工具链（Vite/插件/shadcn），得不偿失。React 19 对项目所用 API（函数组件/Hooks/JSX）完全兼容、无 breaking；T10/T12 实测 24 个前端测试全绿、生产构建 gzip 91KB，无功能缺口。知识库基线 React 18 是知识库级约定，本项目偏离以 ADR 留痕，不反向改知识库基线。

对照选型五维度：成熟度（React 19 已稳定发布、社区主流）、社区（生态活跃，shadcn/Base UI 已跟进）、学习成本（与 18 同 API，零额外学习）、可替换性（若知识库基线后续升 19 自然对齐）、运维成本（零，无需额外配置）。

## ⚠️ 影响

- 正面影响：与最新工具链一致，无需降级踩坑；可享 React 19 改进（如 `use`、ref 作 prop、文档元数据等）。
- 负面影响 / 代价：项目前端偏离知识库基线 18；新人接手若按基线装 18 会与 lockfile 不一致（以项目 lockfile/本 ADR 为准）。
- 需要跟进的事项：持续观察 React 19 生态（shadcn/Base UI）稳定性，若有重大 breaking 再评估；若知识库 `frontend.md` 基线后续升级到 19，本 ADR 自然对齐。

## 🔍 后续验证方式

- T10/T12 已验证：24 个前端测试全绿、生产构建 gzip 91KB。
- 后续前端任务（T22 AI 简报前端、T25 政策时事前端等）持续观察 React 19 兼容性；遇 breaking 记新 ADR。
