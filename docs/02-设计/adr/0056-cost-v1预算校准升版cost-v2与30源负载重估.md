# ADR-0056：cost-v1 预算校准升版 cost-v2（M18 T157，M17 遗留 ⑥）

- 状态：已接受（2026-09-26，V2.0-M18 T157「批次三全量启用回灌前完成」时序红线兑现）
- 决策人：开发工程师（依据[REQ-20260926-15](/docs/01-需求/REQ-20260926-15-M18-批次三与UI2.0收官.md) 拍板五处置表 ⑥「22→30 源常态负载重估：日预算与降级线参数校准，护栏语义/两级降级机制零变更」授权；编排者授权运行时配置 PATCH 操作）
- 关联：ADR-0015（成本口径与护栏派生）、[M17 测试报告](/docs/04-测试/测试报告-信息整合平台-M17-批次二与行业深化.md)（22 源回灌触 DEGRADED 一次 ¥1.24>¥1.20）、ADR-0055（批次三八席与 30 源口径）

## 📌 背景

M17 验收期 22 源回灌负载曾单日触 60% 降级线（DEGRADED 一次，¥1.24 > ¥1.20），M18 批次三 30 源全量启用前若不校准，重负载常态日触线将成为常态开关而非异常防线，L2 事件提取被频繁暂停直接侵蚀行业覆盖率与推荐原料（REQ 时序硬约束：T157 先于批次三回灌）。

## 🎯 决策

**校准计算（llm_call_log 实际数据，scene 5/6/7/8 = 管道成本口径，与 PipelineGuardService.todayCostMicros 同口径）**：

| 步骤 | 数值 | 依据 |
| --- | --- | --- |
| 近 3 日（09-24/25/26）scene5-8 合计 | ¥1.2878 | DB 只读实测（106+61 次 L1 + L2/L3/周报调用） |
| 3 日日均 | ¥0.4293 | 1.2878 ÷ 3 |
| ×30/22 放大 | **¥0.5854/日** | 30 源常态日成本外推（源数线性外推，REQ 授权口径） |
| 期内最高日（09-25）外推 | ¥1.2250 | 0.8983 × 30/22——重负载常态日代理（含批次二回灌残余，保守取用） |
| **落值 dailyBudgetMicros** | **2,600,000（¥2.60/日）** | 降级线 0.6×2.60 = **¥1.56 ≥ 1.2250×1.27**（重日常态日 27% 裕量不触线）；熔断线 ¥2.34；常态日均水位 0.5854/2.60 = **22.5%** |

- **两级比例零变更**（degradeRatio 0.6 / fuseRatio 0.9 保留）——护栏语义与两级降级机制（L0+L1 保底）完全不变，仅预算基数随负载重估抬高；单条成本护栏 ≤0.02 元/条（北极星口径）独立在册：实测 scene5-8 日均 ÷ 日净入库 ≈ ¥0.43/1732 条 ≈ 248 微元/条，20,000 微元红线大裕量。
- **口径升版 cost-v2**：costBasis `cost-v1:initial` → `cost-v2:m18-30src`（Guard 每日校准写回后续接 `cost-v2:calibrated:{date}`，同族衔接）；calibratedPerItemMicros=1100 初值不手改（归 Guard 每日写回机制，实测口径远低于红线）。
- **落值路径**：运行库 runtime_config `pipeline.budget` 单行 PATCH 已执行（带旧值守卫幂等，2026-09-26T06:55:45Z）；代码缺省同步——`PipelineSettings.DEFAULT_DAILY_BUDGET_MICROS` 与 `PipelineRuntimeConfigSeeder` 种子值升 2,600,000（新建库口径一致）。运行中服务的内存快照在编排者重启后生效（重启同时播种批次三 9 席——校准生效先于批次三回灌，时序红线兑现）。
- **校验器上限**：`PipelineBudgetConfigValidator` 对 dailyBudgetMicros 仅正整数下界校验、无既有上限——新值未超任何既有上限，校验器零改动（任务条款「若新值超既有上限」条件不成立）。

## ⚖️ 被否方案与理由

- **维持 ¥2.00 不动**：30 源重负载常态日外推 ¥1.2250 > 降级线 ¥1.20——触线常态化违背 REQ 故事 4 场景 3「常态日不触 60% 降级线」。
- **抬高至 ¥3.00+**：护栏预算过大则 60%/90% 线永不可达，护栏退化为摆设（与「常态开关化」对称的另一种失真）；¥2.60 重日占用降级线 78.5%，仍有触发空间保留防线语义。
- **同时抬高 degradeRatio（如 0.7）**：两级比例是护栏语义本体（REQ 明示零变更）；调基数不调比例是授权范围。
- **手改 calibratedPerItemMicros**：该字段由 Guard 每日「Σ当日管道成本 ÷ 当日净入库」自动写回，手改即引入双写权威冲突。

## 🔁 后果

- 修前红实证：种子/状态/日报三处断言先改期望值（2600000/cost-v2:m18-30src）对旧代码 3 FAIL → 缺省与种子升版后全绿（37/37 含 Guard 边界用例随阈值常量同步）。
- 回灌日（批次三首启 ~24h 回灌窗）成本可能瞬时越过降级线——设计内两级降级语义（L0+L1 保底）兜底，降级事件留痕可查；北极星成本护栏验收取常态日（REQ 拍板四）。
- cost-v2 口径随 costBasis 串在管道状态/日报 basis 快照呈现，验收对账面（T158/T159）可直接断言。
