# ADR-0059：M21 回联提升路径 / 粗筛切分 / 深析降级 / 合成公式（REQ-20260926-17 V2.2-M21）

- 状态：已接受（2026-09-22，M21 设计阶段）
- 日期：2026-09-22
- 决策人：架构设计师（蓝图 M21 段授权：粗筛规则实现 / 深析提示词与调用编排 / 因子表结构 / 合成口径归架构）
- 关联：[技术方案-V2.2-M21](../技术方案-V2.2-M21-全市场漏斗与Top10榜单.md)（§3 裁决全文 + §1 根因量化）、[ADR-0058](0058-M20因子集快照结构与权重模型及双Spike裁决.md)（前置，裁决 2 部分替代）、ADR-0051（FactWhitelistValidator 白名单先例）、ADR-0046（管道护栏 scene 口径）、ADR-0030（行业覆盖根因）、ADR-0017（配置中心热生效）、[REQ-20260926-17](/docs/01-需求/REQ-20260926-17-V2.2-全市场智能标的推荐.md) 裁决 2/3/5

## 📌 背景

M20 交付因子快照与评分引擎（验收 Go），遗留三观察项转 M21 输入：① NO_ASSOC_INDUSTRY 98.7%（5153/5221，已过 ADR-0058「常态 >80% 即立项」触发线）——回联质量提升是 M21 前置；② 总分并列 30.0 × 4952 只——粗筛需可复现次级排序键；③ breakthrough 0/5221——阈值与 F1 分布脱节（max 14.2 vs 阈值 60）。本批同时要落四层漏斗（粗筛 ~300 → LLM 深析 30~50 → Top10）与全市场推荐页第 20 页。设计前完成根因量化（运行库 SQL + 外部源实测，证据方案 §1.1/§1.2）。

## 🎯 决策（七项）

1. **回联提升路径 = 写路径修复 + 双通道回填 + IndustryAssociator 路 C，否决 prompt 增强**。根因量化定位主根因是**行业→标的双向边缺失**（RC3：L1 申万归类 885 行只喂行业热度无标的反哺，subject_master.industry 100% NULL）：① `SubjectRepositoryImpl` UPSERT 改 `industry = COALESCE(?, industry)`——修 ADR-0030 新浪降级轮抹行业的写路径缺陷；② 双通道回填：push2 clist（EastMoneyListClient 已带 f100，实测**间歇可用**——机会主义，SUBJECT_SYNC auto 每日先试东财）+ datacenter `RPT_WEB_RESPREDICT.INDUSTRY_BOARD`（实测 UA+Referer 5/5 页稳定，2933 只 = 56.2% 覆盖，**确定性兜底**，挂 MARKET_TOP_JOB 阶段 0 覆盖率 <80% 触发，只补 NULL 行幂等）；③ `IndustryDirectory.swPrimaryOf` 静态映射东财板块（~104 实测值）→ 申万 31，未收录返 null（安全侧失败）；④ 路 C 成员边 `Association(weight=0.3, age=0, source=INDUSTRY_MEMBER)`——**weight 0.3 封顶使纯成员标的 F2 ≤ ~30，btConductionMin=50 保证「突破」仍要求点名级传导**。**否决**事件提取 prompt 增强（RC1：null-code subjects 15 名池内命中 0，全是非 A 股实体，候选机制已在天花板）与事件侧行业灌成员（行业级事件 ≠ 标的自身催化，F1/F2 分维语义正是切割两者）。**对 ADR-0058 裁决 2 部分替代**：「industry 永远不可靠」的前提（null 覆盖缺陷）已被 ① 修复；associator 仍不读原文、读 SW 映射纯函数输出；幂等口径升级为六输入（+行业成员投影，成员变化属输入变化，同热度滚动同类）。
2. **粗筛切分 = 四键排序 + 三条排除规则留痕**。排序键 `total_score DESC → f_catalyst DESC → last_event_date DESC（NULL 最后）→ subject_id ASC`（V31 为快照表 ALTER 增加 last_event_date 列并回填，双用途：榜单卡「最近事件」）；排除 = ST（名称规则，实测 201）+ 无信号（F1=0 ∧ F2=0，纯并列组）——被排除计数进 funnel_stats 留痕，快照行不动；**不设停牌排除**（无可靠库内判据，v2 行情快照扩字段后再议）；池大小可配（缺省 300，100~800）；**层数断言常驻**（快照行数 > 池 ≥ 深析数 ≥ 榜单数，违反即 JobRunStats ERROR 中止落库）+ deepDiveLimit 硬校验 30~50（30091）——「全量 LLM 逐股永不发生」需求锁定语义的机制化。
3. **深析形态 = 单标的单次调用 + briefType=10 + scene "10"**。否决小批多标的（质量优先：上下文纯净、引用白名单独立、失败爆炸半径最小；token 收益不抵复杂度）。briefType 9 已被行业周报占用，scene 键沿 `briefTypeKey` 契约取 "10"；校验链五步固定顺序（JSON 解析 → 结构 → 引用对账 → 违禁扫描 → 通过/兜底）；**引用对账从 M16 文本白名单裁剪为结构化 id 集合比对**（`citations ⊆ 输入白名单`，比 contains 更强）；违禁黑名单正则 domain 常量；模板兜底数字全部来自结构化输入（ADR-0054「AI 只写叙述」的更保守档——模板连叙述都不用 AI）。
4. **成本护栏 = scene-10 子预算占比触顶降级**。深析日成本（llm_call_log 当日 scene="10" SUCCESS 和，Asia/Shanghai 日界）÷ pipeline.budget.dailyBudgetMicros ≥ deepDiveCostCapRatio（缺省 0.30，蓝图初值）→ 停剩余深析，已深析照常合成，batch.degraded=1 + 页面横幅「深析已暂停，按因子分排序」，次日日界自然恢复；`PIPELINE_SCENES` 扩 "10"（深析计入管道 FUSED 与 cost 报表——蓝图语义：深析预算是管道日预算份额非独立池）。降级三档：单次失败模板兜底（不重试 LLM）/ 连续 ≥5 失败中止剩余（LLM_FAILURE）/ 成本触顶（COST_CAP）——**榜单恒产出，主价值链对深析不设单点依赖**（需求锁定语义）。
5. **合成公式 = final = max(总分, 0.8×总分 + 0.2×深析结构分)**。深析不产生观点分（LLM 自评不可复算破坏防抖），只产生确定性结构分 diveScore = 25 + 10×min(亮点,3) + 10×min(风险,2) + 5×min(有效引用,5)（合格区间 [75,100]，全部从校验后 JSON 结构派生）；max 包络消除高分标的被 0.8 权重拉向 diveScore 的惩罚（深析只加分）；0.2 权重幅面 ≤5 分保证因子分主导排序（M22 防抖在 M21 即成立）；factor_only 标的 final = 总分同序可比。
6. **榜单版本化 = (rank_date, version) 追加式 + 变动留痕**。V31 两表 `market_top_rank`（UNIQUE(rank_date, version, rank_no)）/`market_top_batch`（漏斗计数/降级态/跌出/深析成本，验收与审计读优化）；同日重跑 version+1 追加不覆盖（M22 事件触发沿用，trigger_source 预留）；变动 diff（prev_rank/change_type/dropped）确定性可由两版本重算——留痕是读优化非真相源，不建第三张表。
7. **页面形态 = #/market-top 第 20 页 + 方法论子路由**。方法论为 MarketTop 页内部子路由视图 `#/market-top/methodology`（导航仍 1 项，保「第 20 页」与 4 分组 20 页结构）；否决榜单页折叠区（五段内容塞不下）与独立第 21 页（违蓝图导航口径）。配置编辑面沿留痕窗口先例挂任务中心 MARKET_TOP_JOB Dialog（零新页）。Job 组织 = **独立 CRON 18:00 + 快照日守卫**（FACTOR_SNAPSHOT 17:30 <2min，30min 余量；无依赖编排基建，守卫缺快照 WARN 跳过次日自愈——「无聊但成熟」优先于事件链）。

**方案库采用清单**（先查货架再自研）：03 幂等（(rank_date, version) 语义键 + 纯函数重算）✅ / 07 弹性（裁剪：LLM 失败即兜底不重试、datacenter 整段失败降级继续）✅ / 08 定时任务（第 17 个 ManagedJob 收编）✅ / 09 对账（裁剪：引用 id 集合对账 + 漏斗层数断言两处）✅ / 04 缓存 ❌（最新版本单查询毫秒级）/ 06 MQ ❌ / 12 异步任务 ❌（Job 全程 <15min 同步完成，无需任务表/Worker）。

## ⚖️ 候选方案对比（关键四项）

| 决策点 | 方案 A | 方案 B | 结论 |
| --- | --- | --- | --- |
| 回联提升 | 写路径修复 + 双通道回填 + 路 C 成员边 | prompt 增强 subjects / 事件侧行业灌成员 | ✅ A——RC1 证 null-code 全非 A 股（prompt 收益 0）；事件灌成员污染 F1 分维语义 |
| 成员回填依赖 | datacenter 确定性兜底（2933）+ push2 机会主义 | 仅 push2（全量但间歇封禁）/ 仅 datacenter | ✅ 双通道——push2 单依赖不可靠，datacenter 单依赖覆盖 56% 封顶 |
| 合成分 | 确定性结构分 + max 包络（0.2 权重） | LLM 观点分 / 纯因子分不掺深析 | ✅ A——观点分不可复算破坏防抖；纯因子分使深析对排序零贡献（白做） |
| 深析调用 | 单标的单次 ×30~50 | 小批多标的（省 token） | ✅ A——深析质量是版本最大不确定项，上下文纯净与白名单独立优先；成本已在护栏内 |

## 💡 理由（选型五维度速过）

全案零新组件（两表 + ALTER + 纯函数 ×8 + 第 17 Job + 三端点 + 1 个 datacenter 客户端），成熟度/运维成本沿既有栈满格；可替换性——回填通道收敛在 `IndustryMemberBackfillService` 单点（换源只换 client），深析校验链三件均为 domain 纯函数可独立重写；学习成本——白名单/模板兜底/任务中心 Dialog/管道 scene 四个既有先例的组合，无新模式；社区生态——datacenter 报表接口为 Spike-B 已验证同一端点族的复用。

## ⚠️ 影响

- 正面：F2 从「提及近似」恢复蓝图裁决 1「所属行业传导」原意，NO_ASSOC 预期 98.7% → ≤43.8%（datacenter 兜底）→ 个位数（东财回归后）；漏斗四层全链路带层数断言与三档降级（因子分兜底榜单恒成立）；榜单/深析/引用全量留痕供 M22 统计回算。
- 代价：V31 含 ALTER + 两表 + 阈值守卫 UPDATE（单迁移多对象，回滚 U31 需注记 last_event_date 列保留）；东财→SW 映射表 ~104 值需首跑后按全量值域校补；深析 40 次/日新增 LLM 成本幅面 ¥0.3~0.8（护栏上限 ¥0.78）。
- 跟进：① 首跑后映射表全量值域校补（WARN 计数驱动）；② 深析 estimate 校准（cost-v2 先例）；③ M22 增量链路复用 TopComposer/版本机制；④ 停牌排除判据挂 v2 行情快照扩字段。
