# ADR-0060：M21 T180/T181 实现裁量与 V31 回填 SQL 修正

- 状态：已接受（2026-09-27，M21 T180/T181 开发阶段——方案冲突「停下报告」机制的非冲突面裁量留痕 + 一处方案 DDL 缺陷修正）
- 决策人：开发工程师（方案边界内实现细节裁量权 + 方案 DDL 实证缺陷修正，开发者角色文档「拍板」项）
- 关联：[技术方案-V2.2-M21](../技术方案-V2.2-M21-全市场漏斗与Top10榜单.md)（§4.1/§4.2/§4.3/§4.7.3） · [ADR-0059](0059-M21回联提升路径与粗筛切分及深析降级与合成公式.md)（七裁决被本批实现）

## 📌 背景

T180（回联质量提升前置）/T181（粗筛层）按方案实现过程中，一处方案 DDL 经迁移单测实证存在语义缺陷；另有五项方案未明说的实现裁量需留痕（映射值域来源 / 回填通道执行序 / 存储口径 / 配置链落批 / 断言分层），供 T182/T183 对接与评审参照。

## 🎯 决策（六项）

1. **V31 存量回填 SQL 修正（方案缺陷，实证修前红）**：方案 §4.2 原文以「三段 UNION 的标量子查询」直赋 last_event_date——SQLite 对多行标量子查询取「去重排序后首行」，UNION 去重即升序 → 实际取**最小**日期。迁移单测实证 `expected: "2026-09-21" but was: "2026-09-15"`（catalyst 09-18 / fundamental 09-21 / risk 09-15 取了 09-15）。修正为外层再包 `SELECT MAX(d) FROM (… UNION …)`——与方案文字语义「三维护据事件最大日期」一致，仅 SQL 形态修正；V31 尚未应用于任何库（服务未重启、dev 库未动），直接改迁移文件不违 Flyway 已应用不可改约定。U31 无对应段（列保留无害，回滚口径不变）。
2. **swPrimaryOf 映射值域来源**：方案无附录值表（§4.1.3 仅给示例与「~104 实测值」量级）。开发期 curl 级预检实证（2026-09-27，datacenter `RPT_WEB_RESPREDICT` 30 页 × 100 行、页间隔 500ms、2933 只零缺失）取得**全量值域 127 值**，按申万 2021 一级分类树逐一映射（127 板块 → 31 申万全覆盖，单测断言值域恰 127 + 目标全为申万枚举）。超样收录优于样本外推（方案风险表「首跑后按全量值域补表」的前置完成）；值域漂移由规模守护断言预警。
3. **回填双通道执行序**：服务内通道 A（datacenter，确定性、30 页 ~15s）先行，通道 B（push2 clist，机会主义、56 页 ~84s 且封禁间歇）仅当 datacenter 后覆盖率仍低于阈值才尝试——重外呼零收益裁剪。通道语义与方案 §4.1.2 一致（clist 主路径仍是 SUBJECT_SYNC 每日轮 + COALESCE 持久化，本服务内 clist 为机会主义补位）。
4. **回填存储口径**：`subject_master.industry` 写**东财板块原文**（方案 §4.1.2 冻结 SQL `SET industry=?` + §3.1「该字段变为东财口径」），SW 映射收口在快照读侧 `swPrimaryOf` 单一事实源——不预映射存储，避免双处映射漂移（任务提示「INDUSTRY_BOARD→swPrimaryOf→只补 NULL」为链路压缩表述，以方案原文为准）。
5. **market.top 配置链落批**：键/缺省/读侧 Settings/校验器 30091/门面/种子随 **T180 提交**落地（回填预检消费 memberCoverageFloor，先于端点存在）；GET/PATCH 端点与前端 Dialog 随 T181 提交。两提交各自可编译可测试全绿。
6. **层数断言分层**：PoolBuilder.build 内只做**结构性**校验（池⊆快照行、深析⊆池）——方案 §4.3.2「合格 < poolSize 全取」允许池=合格数=快照行数的退化态；§4.3.4 的**严格四值链**（快照行>池≥深析≥榜数）以公开 `assertFunnelLayers` 落在 Job 阶段 3（T183）落库前调用面（彼时 topSize 已知）——「全量 LLM 逐股」形态在落库前中止，与方案 §4.3.4 的「Job 阶段 3 落库前断言」原文对齐。

## ⚖️ 影响与理由

- ①是唯一语义修正（其余为裁量）：方案文字语义无歧义，仅 SQL 形态错误，实证后修正并在迁移文件与单测镜像处双向注记；若架构复核认应另立 V32 修正（V31 已应用场景），本仓库当前无已应用实例、不构成回滚面。
- ②③④均在 ADR-0059 裁决 1 的语义边界内（映射安全侧失败 / 机会主义不阻塞 / 东财口径单调稳定），仅确定方案留白的细节。
- ⑤纯提交序列裁量（任务拆解表 T181 列含配置键，但 T180 的回填预检消费该键——先落基础件后落端点，边界自洽）。
- ⑥避免纯函数在退化小市场输入上误抛（§4.3.2 与 §4.3.4 的并集语义：结构不变量常驻 builder，生产形态严格链常驻 Job）。
