# ADR-0044：批次一官方与报纸六 HTML 源实测修正与 NONE 游标裁量

- 状态：已接受（2026-09-25，V2.0-M14 批次一 T111/T112 实现偏差留档）
- 日期：2026-09-25
- 决策人：开发工程师（依据[REQ-20260925-11](/docs/01-需求/REQ-20260925-11-M14-批次一源接入与抓取大盘.md) T111/T112「栏目路径按现行结构对照」授权与 ADR-0042/0043「先实测再写适配」模式）
- 关联：ADR-0038（info_source 注册表）、ADR-0039（news_item 去重）、ADR-0041（FetchResult 截断信号）、ADR-0042/0043（实测修正先例）、[V2.0 信息平台普查报告](/docs/02-设计/V2.0-信息平台普查报告.md) §2.2/§2.4（六源普查样本）

## 📌 背景

T111（发改委/证监会/统计局官方源 ×3）+ T112（证券时报/第一财经/21 财经报纸源 ×3）六源预检实测（端点各 curl 一次 + robots 复核；失败端点的纠正性追测见下）发现与普查样本五处差异与两项增量口径裁量：

1. **证监会普查端点冻结**：`www.csrc.gov.cn/csrc/c100028/common_list.shtml` 实测 200 但返回**冻结快照**——页面生成时间 2021-12-12 08:00:13、条目最新 2021-12-10，与普查 16172B 字节数完全一致（普查时即为同一快照）；换 UA/Accept-Language 复测一致。现行列表页变体 `common_xq_list.shtml` 服务端渲染为**空** `ul#list`（客户端填充，page.js 仅分页渲染无数据端点）。
2. **证监会现行结构对照结论**：站点本身新鲜（首页生成时间 2026-09-25，要闻条目至 2026-09-18）——唯一服务端渲染的新鲜窗口为**首页要闻 tab 块**（`li.li-height > a + span.time`，置顶 `li.first` 为 c106311 领导活动跨栏条目）。
3. **证券时报现行栏目路径**：旧快讯路径 `/article/list/kuaixun.html` 与 RSS 均 404（普查已证）；现行要闻栏目入口由首页 `data-items` 标签对照得出：`/article/list/yw.html`（55KB 服务端渲染，首屏 10 条 + `data-url` 无限滚动）。
4. **发改委列表页形态演进**：普查记 `/xxgk/zcfb/fzggwl/` 为 4339B（父路径 JS 跳转中间态）；实测为 43KB 完整列表页（`div.list > ul.u-list > li`，53 条，含「相关解读」跨栏条目混排——`../../jd/jd/` 相对链接）。
5. **时间格式碎片化**：统计局/发改委为日期墙钟（`yyyy-MM-dd` / `yyyy/MM/dd`，日粒度）；证监会首页块为 `MM-dd`（无年份）；证券时报为 `HH:mm`（当天）；一财为相对时间（「N小时前」「昨天 HH:mm」）；21 财经为完整日期与「N分钟前」混排（全角空格分隔作者）。

## 🎯 决策

- **六源全部 preset 通道**（新增 `AbstractHtmlListFeedAdapter` 基类承载共用取数管线与中文墙钟解析，jsoup 解析列表页），bean 名 `ndrcPolicyAdapter` / `csrcNewsAdapter` / `statsGovReleaseAdapter` / `stcnNewsAdapter` / `yicaiNewsAdapter` / `jingji21FinanceAdapter`，目录 seed-if-absent 补种（7→13 预置，REQ 累计源数口径）。
- **证监会走首页要闻块**（端点 `https://www.csrc.gov.cn/`，`/csrc/c100028/c\d+/content.shtml` href 锚定要闻栏条目、置顶跨栏条目排除）：普查端点冻结属「结构不匹配」类预检发现，官方源按 REQ「不擅自替换」保留源本身，现行结构对照落在首页块——站点结构属实现细节裁量，未变更需求范围。
- **时间折算口径**：统一 `parseChineseWallClock`（Asia/Shanghai 墙钟 → Instant）——相对时间以注入 `Clock` 折算（可测）；`MM-dd` 无年份取时钟当年（结果晚于时钟 +1 天回看上一年）；`HH:mm` 当天（晚于时钟回看前一天）；跨年/零点边界有矩阵用例。**日粒度日期取当日北京零点**（无小时信息，较回落抓取时刻更接近真实发布时间，感知延迟口径对该粒度失真为已知取舍）。
- **cursorType=NONE 全六源裁量**（增量靠 (source_id, external_id) 唯一索引幂等吸收，沿 ADR-0043 东财宏观先例）：①发改委/统计局/证监会日期仅日粒度——TIME 游标「遇已见止」漏同日新条目；②证券时报/一财经首屏 id 序列实测存在相邻乱序对（4199183 先于 4199184、103378038 先于 103378039）——ID 游标漏排序靠后的新条目；③21 财经列表按编辑排序非时间序。六源均为首屏一页窗口（10~53 条）× 20~60min 频控，全量重发量级可忽略。
- **externalId 口径**：证券时报/一财经/证监会取 URL 数值 id 段（4199211 / 103378345 / c7659506）、21 财经取 article uuid；发改委/统计局列表无显式 id → 解析后绝对 URL 作 externalId（任务口径「列表页无显式 id 时 URL 作 externalId」）。
- **频控落位**：官方三源 60min（REQ 频段 30~60 上限，日级源 + 证监会首页 221KB 大页礼貌抓取）；证券时报/21 财经 30min、一财经 20min（REQ 报纸频段 15~30，一财快讯密度较高取中值）。

## ⚖️ 被否方案与理由

- **证监会 ID/TIME 游标**：首页块仅 5 条且 c106311 置顶条目 id 序列跨栏，游标收益为零、误判面非零。
- **证监会 common_xq_list 客户端数据端点逆向**：无公开数据端点可见（page.js 仅分页 UI），逆向未知接口违反普查 §6 红线精神。
- **一财经「2025-11-03 14:49」等绝对格式**：属主列表外区块（旧文推荐），主列表（`#newslist > a`）实测仅相对时间与「昨天」两格式——解析器仍支持绝对格式（防御性，未来格式演进免改），fixture 只以实测格式为准。
- **首页块作通用 html_template 通道**：HTML_TEMPLATE 预留未开放（ADR-0038），六源结构各异且需栏目锚定/跨栏排除等代码语义，preset 通道正确。

## 🔁 后果

- 既有 7 预置源与六源业务域零影响（纯新增：基类 + 六适配器 + 目录六行，种子 seed-if-absent 存量行不动；不重启不生效——运行中实例未含新源属预期，部署注记沿 ADR-0043）。
- 证监会首页块仅 5 条/轮：REQ「官方源首轮 ≥3」满足；若后续官方站恢复 common_list 新鲜渲染，切换回列表页端点 = 目录行 PATCH（无需发版）。
- robots/条款复核留档（REQ 场景 5 必检项）：ndrc robots 403（WAF 拒读）→ RFC 9309「无 robots 文件 = 无限制」（REQ 指定口径）；csrc robots 302 跳 HTML → 无 robots 文件；stats/stcn robots 404 → 无限制；yicai robots 200 禁 `/api/`、`/search`（本源走 `/news/` 不涉）；**21jingji robots 通配 Allow 但显式禁 GPTBot/Google-Extended/anthropic-ai/ClaudeBot/CCBot/Bytespider 等训练类爬虫——聚合展示用途不受影响（REQ 非功能条款口径），M15 AI 管道启动前复核条款，有疑虑则该源内容不入深度分析**。
- 六源均无源站封禁记录（预检全 200）；21 财经 m 站绝对链接若后续站方切换 www/m 主机形态，externalId（uuid）不受影响。
- 后续 HTML 列表类源复用基类：实现 `parseList` + `referer` 两方法即可（中文墙钟矩阵已覆盖六种实测格式）。
