# ADR-0030：A 股列表源备选与自动切换——新浪 SinaSubjectListClient + 路由（REQ-20260924-04 / M7）

- 状态：已接受（2026-09-24，M7 push2 封禁窗口补强）
- 日期：2026-09-24
- 决策人：开发工程师（依 ADR-0027 备选路径 + 编排者 2026-09-22 新浪端点实测落地，PM 已裁行业口径）
- 补充：ADR-0027（数据源选型，新浪为 A 股备选）、ADR-0029（`SubjectListSource` 端口——换源只换实现类）、技术方案-标的池定时同步.md §4.2.1

## 📌 背景

M7 交付后本机触发 push2 IP 级封禁（clist 空响应，恢复慢）——A 股桶连日失败，首跑建池被阻塞。ADR-0027 已预判该路径（「切新浪（A 股）需改 Client 一层，DTO 不变」），ADR-0029 的 `SubjectListSource` 端口为此预留了可替换性。2026-09-22 编排者实测新浪 A 股列表端点可用（需 UA + Referer，`num=100` 分页稳定），**无总数字段**（翻到空页/不足 num 即止）、**无行业字段**、`node=hs_a` 含北交所 `bj` 前缀行、**新浪港股无可用节点**（hk_stock/hk_quotes/hk 均空）。

## 🎯 决策

1. **新增 `SinaSubjectListClient`**（infrastructure/aggregation，实现 `SubjectListSource`）——**仅服务 A_SHARE_STOCK 桶**（非 A 股桶调用直接抛不支持）：
   - 分页 `page` 递增 `num=100`，终止条件 = 空页（`[]` / 字面量 `null`）或不足 `num` 的短页；**无 total 完整性校验**（源无总数字段），改为**双防假空**：首页空即放弃 + 映射后全量空即放弃（源故障返空不能当「全量为空」，否则整桶误判缺失）。
   - 字段映射对齐既有 SubjectSnapshot 形态：`symbol` 前缀 `sh`→SH（secid `1.代码`）/ `sz`→SZ（secid `0.代码`）——secid 与东财快照同构，行情/估值链路零改造；**industry 恒 null**（源无行业字段，PM 裁「以源为准」：降级轮会把东财行业覆盖为 null）；**`bj`（北交所）跳过**——不在需求口径（ADR-0027 fs 不含北交所）且 secid 派生规则未实测，不引入虚构主数据（待 PM 变更控制再议）。
   - 软限速与弹性：每请求 UA + `Referer: https://finance.sina.com.cn`（对齐 SinaNewsClient）；页间隔复用 `subject.sync.page-interval-millis`（与东财共用一个礼貌旋钮）；`subject.sync.max-pages` 防御；ResilienceSpec 超时 **10s**（§3.1 实测新浪冷响应 6.8s，较东财 5s 放宽）/ 重试 1 / 退避 500ms，日志标签 `sina-hq-node`。
2. **新增 `RoutingSubjectListSource`**（@Primary 组合实现，infrastructure/aggregation）——多源选择收拢在此，引擎 `SubjectSyncService` 仍只依赖端口、零改动（ADR-0029 可替换性兑现）：
   - **非 A 股桶恒东财**（新浪无港股节点）；A 股桶按 `subject.sync.a-share-source: auto | eastmoney | sina`（默认 **auto**）路由。
   - auto：东财 A 股桶拉取失败（重试耗尽 / total 不符等）→ 记 WARN → **自动降级新浪整桶重拉**（全量语义无半截数据，非增量续传）；新浪也失败才抛桶失败（新浪异常上抛，东财原因挂 `suppressed` 留诊断链）。
   - eastmoney/sina：强制单源，失败即桶失败（排障用——验证降级逻辑是否为故障源）；配置笔误启动即失败（fail-fast），空值容错回落 auto。
3. **配置面**：`subject.sync.a-share-source: auto` 新键（application.yml）；新浪端点/Referer 可配 `adapter.sina.stock-list-url` / `adapter.sina.stock-referer`。

## ⚖️ 被否方案与理由

| 被否方案 | 理由 |
| --- | --- |
| 新浪做强接主选 | 无行业字段（首启全量覆盖丢行业口径）、无北交所 secid 派生——东财恢复后应自动回归主选，auto 每轮先试东财 |
| auto 降级做增量续传（东财拉一半接着新浪拉） | 两源口径不同（行业有无/北交所），拼接产物口径混杂且无 total 可校验；全量语义下整桶重拉最简且无半截数据 |
| 防假空仅靠「首页空」一关 | 行级过滤（bj 跳过/空名丢弃）可能把非空首页吃成空结果——补「全量结果为空」兜底同语义 |
| 港股也挂新浪备选 | 实测新浪无港股节点（hk_stock/hk_quotes/hk 均空）——港股备选薄弱走需求兜底（ADR-0027 既有结论），不虚构可用性 |
| 北交所行映射入库（bj→BJ 前缀/secid 猜测 0.代码） | secid 派生规则未实测，虚构主数据污染取数键；口径变更待 PM 变更控制（本 ADR 显式跳过） |

## 💡 后果

- push2 封禁期间 A 股桶自动走新浪建池（Must 不阻塞）；封禁解除后东财自动回归主选（auto 每轮先东财），无需人工切回。
- 降级轮的行业口径：A 股既有行的东财行业被覆盖为 null（PM「以源为准」），东财回归后下一轮自动补回；跨轮口径抖动可接受（industry 为自由文本展示字段，不参与匹配/路由）。
- 新浪分页无 total 校验 → 丢页风险由「翻到空页才终止」语义兜底（num=100 稳定，实测无中间页截断）；max-pages=200 防御失控。
- 类清单净增 `SinaSubjectListClient` / `RoutingSubjectListSource` 两文件 + 三测试类；分层不变（infrastructure 实现应用端口，ArchUnit 全绿）。
