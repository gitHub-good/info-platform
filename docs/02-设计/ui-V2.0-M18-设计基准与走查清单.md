## 📌 一、暗色 tokens 升级前后对照（`frontend/src/index.css` .dark 块）

| Token | 升级前（v1） | 升级后（v2） | 变更性质 |
| --- | --- | --- | --- |
| `--background` | `oklch(0.145 0 0)` | `oklch(0.13 0 0)` | 暗色深化一档（页面底更深） |
| `--card` / `--popover` | `oklch(0.205 0 0)` | `oklch(0.185 0 0)` | 卡片层随底深化，与背景层次拉开 |
| `--secondary` | `oklch(0.269 0 0)` | `oklch(0.245 0 0)` | 次级面收紧 |
| `--muted` | `oklch(0.269 0 0)` | `oklch(0.235 0 0)` | 骨架/弱面加深（骨架动效更沉） |
| `--muted-foreground` | `oklch(0.708 0 0)` | `oklch(0.75 0 0)` | **次要文字对比度提升**（对 0.13 底约 4.8:1 → 5.9:1，AA 强化） |
| `--border` | `oklch(1 0 0 / 10%)` | `oklch(1 0 0 / 12%)` | 边界可辨（卡片/表格分隔线） |
| `--input` | `oklch(1 0 0 / 15%)` | `oklch(1 0 0 / 18%)` | 输入框/下拉边框可辨 |
| `--ring` | `oklch(0.556 0 0)`（纯灰） | `oklch(0.68 0.11 250)`（蓝系低饱和） | 焦点环可见性（键盘可达性），不引入品牌色喧宾 |
| `--chart-1..5` | 灰阶五阶（0.87/0.556/0.439/0.371/0.269） | 蓝/青/琥珀/紫/玫红（`0.62 0.16 255` 等） | 图表色板带色相（蓝图 G 域「图表组件」基准；北极星迷你趋势首个消费者 `bg-chart-1/70`） |
| `--sidebar` | `oklch(0.205 0 0)` | `oklch(0.165 0 0)` | 侧栏随全局深化 |
| `--sidebar-primary` / `--sidebar-ring` | `0.488 0.243 264` / 灰 | `0.62 0.16 255` / 蓝系 | 与 ring/chart-1 同源蓝系，导航强调色统一 |
| `--primary` / `--accent` / `--destructive` / `--radius` | — | 不变 | 主按钮/语义色/圆角零变化（布局红线） |

`:root`（亮色块）随同升级 ring/chart（形态一致），亮色主题本站未启用（`index.html` 恒 `class="dark"`），仅保持契约完整。

## 📌 二、全局类与基准规则（`@layer base` 新增）

| 规则 | 内容 | 受益面 |
| --- | --- | --- |
| `color-scheme` | `.dark { color-scheme: dark }` | 原生控件（滚动条/下拉/日期）暗色一致 |
| 抗锯齿 | `body { antialiased }` | 全站文字渲染 |
| 字阶细节 | `h1 { letter-spacing: -0.015em }` | 18 页大标题排版统一 |
| 数值排版 | `table { font-variant-numeric: tabular-nums }` | 大盘/热度/成本/任务等数字密集表对齐 |
| 选区反馈 | `::selection` 蓝系 30% 底 | 暗色下选区可见 |
| 暗色滚动条 | webkit 细滚动条（8px，thumb 14%/hover 22%） | 横向滚动表格、>30 源形态滚动容器 |

**间距阶基准**（`@theme` 具名变量 + 文档约束，存量页面不回改——「微升级不改布局」红线）：页面内边距 `p-4 sm:p-6`、区块纵向 `gap-6`、卡片网格 `gap-4`、卡内条目 `gap-2~3`（`--spacing-page/--spacing-section/--spacing-card-grid/--spacing-card-inner` 已入 `@theme` 供新代码取值）。

**字阶基准**：页面标题 `text-xl font-medium`、区块题 `text-sm font-medium text-muted-foreground`（工作台/北极星沿用）、指标主值 `text-xl/2xl tabular-nums`、徽章恒 `text-xs`。基础组件（badge/button/card/skeleton/table/tabs/pagination）零改动、随 token 被动刷新。
