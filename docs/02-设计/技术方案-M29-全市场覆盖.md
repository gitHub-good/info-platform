## 1. 结论先行

**总判断：港美股四件套地基全部落在 Spike-E 实证可达端点上（零 push2 依赖），五功能点亮全部为既有机制「扩市场维」，A 股链路结构性零触碰。** 承载收敛为：**1 个新 Job 键**（`HKUS_MARKET_SNAPSHOT` 第 20 键）+ **1 个 DDL 迁移 V37**（六表重建加 market 维 + 两列扩展 + 一张新表）+ **V38 模板种子** + **4 个新资讯源**（34→38）+ **2 个新客户端类**（F10 列表 + 新浪行情）+ **既有类扩分支**（腾讯 US 布局 / 美股桶 / 代码派生）。总量级：港 2600 全量 + 美 ~3000 精选 = 5600 只，行情 2688 请求/日，LLM 调用次数零新增。

1. **口径版本 `mainline-v1:m2`**：三维权重（0.40 价格 / 0.35 热度 / 0.25 事件）与持续性硬门槛结构**零变更**，全部输入按市场切横截面——百分位**市场内**计算、价格维（0.5 当日 + 0.5 五日）取 `industry_market_snapshot(market)`、热度维取 `industry_heat_snapshot(market)`、事件维按「事件关联标的市场 = market」分桶后命中各自枚举。
2. **持续性门槛跨市场独立口径**：`persistent_days` 按市场内序列独立累积（近 5 交易日 ≥2 日上榜/价格前 1/3，阈值共用 `industry.mainline` 配置键）；港美股历史 < persistMinDays 时**沿 M27 bootstrap 先例**免门槛按主分出榜 + batch `funnel_stats.bootstrap=true` 留痕 + `persistentDays` 如实展示，攒足自动恢复严格口径（拍板五，零新机制）。
3. **龙头不扩展（W1）**：港美股榜 `leaders` 恒 `[]`，detail 端点给 `leadersAvailable=false + reason`（占位不静默）；A 股龙头链路零触碰。
4. **同输入重算零漂移**：市场化为纯参数化扩展，纯函数性质构造性保持（T255 单测断言三市场各一轮）。

## 7. market-top 分市场漏斗（裁决 ⑧ 展开面）

1. **四层漏斗同构不同数据**：池（market ∩ status=1）→ 粗筛（四键可复现切分，沿 ADR-0059）→ 精排 → Top10，各层数量落 `funnel_stats` 可查。
2. **价值维缺省再归一**：港美股 F3（基本面）/F5（估值）权重置 0 后**剩余维再归一**（非简单低分），`data_flags` 增 `NO_FUNDAMENTAL_MARKET` / `NO_VALUATION_MARKET`，`dimensionMissing` 端点直读（拍板四）。
3. **深析成本护栏**：+20 卡/日（HK 10 + US 10）全走 scene-10 既有预算位（≤30% 管道日预算触顶降 FACTOR_ONLY，ADR-0059 降级链零新机制）；开关 `market.top.hkusDiveEnabled` 热生效。
4. **合规**：港美股榜免责逐榜必载（recscore 口径延续）、违禁扫描覆盖三市场产出、增量重评联动（M22）按 market 隔离触发。
