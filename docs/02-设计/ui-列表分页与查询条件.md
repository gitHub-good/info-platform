## 🎯 1. 设计总览与关键决策

| # | 决策 | 结论 | 依据 |
| --- | --- | --- | --- |
| D1 | 分页组件实现 | **自研 `components/ui/pagination.tsx`**（shadcn 风格受控组件），不引入 shadcn CLI 的 pagination 配方 | 官方 Pagination 是 `<a>` 链接导航形态，无在途禁用/受控当前页概念，与「切页在途禁用 + 失败重试」诉求不匹配；仓库先例即「shadcn 风格自研 + 零原语依赖」（`input.tsx` 注释明示、Switch/原生 select 同款裁决 M4-D5）；组成件全部既有（Button + 原生 select + cn），零新依赖红线达成 |
| D2 | 分页条显隐 | **total = 0 → 整条隐藏；total > 0 恒显**（单页时收敛为精简态：仅「共 N 条 + 第 1/1 页 + 每页条数」，无翻页按钮） | PRD 场景 2.3「筛后无结果分页导航隐藏，不出现第 1/0 页」；PRD 场景 1.3 明文「页码导航变为第 1/1 页」——单页若整条隐藏，每页 50 时将**锁死无法切回 10/20**；见 §7.3 澄清 1（任务简报「单页隐藏分页条」与冻结 PRD 冲突，按 PRD 执行） |
| D3 | 页码折叠规则 | **总页数 ≤7 全显；>7 时首末页恒显 + 当前页 ±1，相邻差 =2 补位、差 ≥3 插一个省略号**；任何情况下数字按钮 ≤7 个 + 省略号 ≤2 个，宽度恒定 | 检索/审计心智「失败集中在第几页」要求首末页与当前邻域直达；宽度恒定避免暗色窄屏换行抖动；纯函数导出可单测（§2.3） |
| D4 | 跳页输入框 | **不做**（从简裁决） | 冻结验收场景的「跳页」= 点击页码（场景 1.2），无输入框场景；首末页恒显 + ±1 折叠已覆盖定位主路径；少一个受控输入即少一组校验/三态（超界/非数字）；页数持续增长（>50 页）时随「分页状态进 URL」（PRD Won't 另立项）一并考虑 |
| D5 | 翻页在途与失败 | **翻页/条数切换：保留当前页数据 + 分页条禁用（`aria-busy`）+ 「加载中…」提示行；失败：保留数据 + 错误行 + 重试按钮，控件恢复可用；筛选/搜索变更：骨架首屏（沿用 `loadFirst` 模式）** | PRD 场景 1.4「切页失败保留第 1 页内容不清空 + 重试」、全站「错误不清已有数据」基线；筛选变更是新结果集（骨架合理），翻页是同结果集内位移（保留数据防闪跳）——两类 loading 分开管理（§5.1） |
| D6 | Job 状态筛选形态 | **分段按钮组 4 档：全部 / 成功 / 失败 / 执行中**（非任务简报的 3 档） | 冻结 PRD 故事 3 原文「按状态筛选（全部/成功/失败/执行中）」；`STATUS_META` 已含执行中；复用 `WindowSwitcher` 按钮组先例（default 高亮 / outline 未选） |
| D7 | 政策关键词搜索 | **显式触发**（搜索按钮 + Enter），不做输入防抖自动查询；trim 后 <2 字符禁用搜索按钮；空输入提交 = 清除关键词回全量 | 检索型列表心智是「确认后查询」（PRD 场景 4.1「输入并触发查询」）；PRD 非功能「关键词 ≥2 字符」前端先行拦截；防抖自动查询属消费流搜索联想形态，本期不引入 |
| D8 | 无结果空态 | **两页统一范式：主文案区分条件来源（关键词优先引用）+ 副文案引导 + 「清除筛选」CTA**；完全无筛选的无结果维持现状 muted 文案、无 CTA | PRD 场景 4.2「区分性空态文案（口径交 UI）+ 分页导航隐藏」；空态必须给出去向（M4 §4.1 基线）；无筛选时无可清项，CTA 无意义 |
| D9 | URL 与分页状态 | **分页/筛选状态一律不进 URL**；`#/job-logs?jobName=` 预过滤入口语义保留（初始 state，不回写） | PRD Won't「分页状态进 URL 另立项」；现状 `App.tsx` key 重挂载机制不动，清除筛选 CTA 只改组件 state（§6 给开发 2） |

## 🧩 2. 通用分页组件基线 `ui/pagination.tsx`

### 2.1 布局线框

```
多页态（totalPages ≥ 2）
┌────────────────────────────────────────────────────────────────────────┐
│ 共 45 条          第 2 / 3 页  ⟨上一页⟩ [1] [2] [3] ⟨下一页⟩   每页 [20▾] 条 │
└────────────────────────────────────────────────────────────────────────┘
  左：总数文案（text-sm text-muted-foreground）
  右：页码指示 · 上一页/下一页（ghost 图标按钮）· 页码按钮 · 每页条数（原生 select）
  容器：mt-4 flex flex-wrap items-center justify-between gap-x-4 gap-y-2
        border-t border-border pt-4（与列表区分隔）

单页精简态（total > 0 且 totalPages = 1）
┌────────────────────────────────────────────────────────────────────────┐
│ 共 45 条                                第 1 / 1 页            每页 [50▾] 条 │
└────────────────────────────────────────────────────────────────────────┘
  无翻页按钮（无目标可去），保留总数/指示/条数——否则 size=50 时无法切回（D2）

隐藏态（total = 0，含筛后无结果）→ 组件 return null，整条不渲染

窄屏（<sm）：右组自然换行到第二行左对齐；「共 N 条」与「每页条数」同行收尾
┌──────────────────────────────┐
│ 共 45 条            每页 [20▾] 条 │
│ 第 2 / 3 页 ⟨上一页⟩[1][2][3]⟨下一页⟩│
└──────────────────────────────┘
```

- 页码指示「第 x / y 页」**常驻可见**（两种态都渲染）：满足 PRD 场景 1.1「页码导航第 1/3 页」逐字断言，也是审计「口头同步页码位置」痛点的直接载体。
- 每页条数选择器：原生 `<select>`（`IndustryFilter` 同款样式类，高度对齐按钮 h-8），选项 **10 / 20 / 50**，默认 **20**；`aria-label="每页条数"`。

### 2.2 页码按钮样式

| 元素 | 样式约定 |
| --- | --- |
| 页码按钮（非当前页） | `Button variant="ghost"`，`h-8 min-w-8 px-1.5 rounded-[min(var(--radius-md),12px)]`（min-w 保证 3~4 位数页码不挤压） |
| 当前页 | 同上但 `variant="default"`（bg-primary 高亮）+ `aria-current="page"`——不裸用位置颜色，aria 与视觉双通道 |
| 上一页 / 下一页 | `Button variant="ghost" size="icon"` + `ChevronLeft / ChevronRight`，`aria-label="上一页"/"下一页"`；首/末页时 `disabled`（原生禁用态，不隐藏） |
| 省略号 | 非交互 `<span aria-hidden="true" class="px-1 text-muted-foreground select-none">…</span>`——不可聚焦、不进 Tab 序 |
| 总数文案 | `text-sm text-muted-foreground`「共 N 条」，N = 响应 total（筛选后总数，前端不累计） |
| 页码指示 | `text-sm text-muted-foreground`「第 x / y 页」 |

### 2.3 组件 API 与折叠算法

```tsx
interface PaginationProps {
  page: number;                 // 当前页（1 起，受控，无内部 state）
  pageSize: number;             // 每页条数（受控）
  total: number;                // 筛选后总条数（响应 total 字段）
  onPageChange(page: number): void;
  onPageSizeChange(size: number): void;
  disabled?: boolean;           // 在途禁用（页面 pageLoading 传入 → 全控件 disabled）
  pageSizeOptions?: number[];   // 默认 [10, 20, 50]
  label?: string;               // <nav aria-label>，默认「分页」（页面传「政策列表分页」等）
}
// total <= 0 → return null；totalPages = Math.max(1, Math.ceil(total / pageSize))
```

折叠算法（**导出纯函数 `getPaginationItems(current, totalPages): Array<number | 'ellipsis'>` 供组件单测**）：

```
1. totalPages ≤ 7 → 返回 [1..totalPages] 全显
2. 否则构造数字集合 S = {1, totalPages, current-1, current, current+1}（剔除 <1 / >totalPages）
3. 升序遍历 S：相邻两数差 = 2 → 补上中间页码；差 ≥ 3 → 插入一个 'ellipsis'
```

渲染示例（自测用例）：

| current / totalPages | 渲染结果 |
| --- | --- |
| 2 / 3 | `[1] [2] [3]` |
| 1 / 8 | `[1] [2] … [8]` |
| 3 / 8 | `[1] [2] [3] [4] … [8]` |
| 5 / 12 | `[1] … [4] [5] [6] … [12]` |
| 11 / 12 | `[1] … [10] [11] [12]` |
| 1 / 100 | `[1] [2] … [100]` |

任何输入下数字按钮 ≤7 个、省略号 ≤2 个（宽度恒定，D3）。

### 2.4 交互与三态

| 态 | 触发 | 表现 |
| --- | --- | --- |
| 默认 | — | §2.1 布局；页码/上下页/条数全部可点 |
| 在途 | 页面 `pageLoading=true` 传入 `disabled` | 全控件 `disabled`（原生 `disabled:pointer-events-none disabled:opacity-50`）；列表区容器 `aria-busy="true"`；分页条上方状态行显示 muted「加载中…」（`aria-live="polite"`）；**列表数据保留不闪骨架**（D5） |
| 无数据 | `total=0` | 组件 `return null` 整条隐藏（PRD 场景 2.3；空态由页面渲染，§3.3/§4.3） |
| 错误 | 翻页请求失败 | 组件本身不渲染错误（纯受控）；页面在分页条上方渲染错误行 `text-sm text-destructive`（`role="alert"`）「加载第 {p} 页失败：{原因}」+ outline sm「重试」按钮（重发**同一目标页**）；**当前页数据保留、分页控件恢复可用**（用户直接点其他页 = 换目标重试，等效通道） |
| 单页 | `totalPages=1` | 精简态（§2.1）：无翻页按钮，保留总数/指示/条数选择（D2） |

交互细则：

1. **切页**：点击页码 / 上一页 / 下一页 → 组件回调目标页 → 页面发请求（整体替换语义，非追加）；**页码高亮保持当前页直到成功**（不提前跳，避免失败后高亮与数据错位）；成功后整体替换条目 + 高亮切换 + 滚回列表顶部（§5.2）。
2. **每页条数切换**：回调新 size → 页面**重置 page=1** 再发请求（PRD 场景 1.3）；选择器本身不重置（受控显示当前值）。
3. **size 上限**：前端选择器仅提供 10/20/50，不产生 size>50 请求（PRD 场景 1.6 前端侧责任；后端防御见 §7.2 联判 3）。
4. **键盘可达**：页码/上下页为原生 button（Tab 聚焦、Enter/Space 触发），条数为原生 select；无 roving tabindex、无跳页输入框（D4）。容器 `<nav aria-label={label}>` 构成语义分区。

## 🔁 5. 筛选 × 分页联动语义（两页通用，T64/T65 实现基准）

### 5.1 两类 loading 分离

```
listLoading（首屏 / 筛选·搜索·时间窗·状态变更 → 新结果集查询）
  → 骨架屏 + 筛选控件禁用 + 分页条隐藏（无 total 可示）

pageLoading（同筛选条件下的翻页 / 条数切换）
  → 列表数据保留 + 分页条 disabled + aria-busy + 「加载中…」状态行
  → 成功：整体替换 + 高亮新页 + 滚回列表顶部（PRD 场景 1.2）
  → 失败：保留当前页 + 错误行 + 重试（PRD 场景 1.4）
```

> 说明：条数切换（PRD 场景 1.3）虽也回到第 1 页，但结果集未变（同筛选条件重排），归「保留数据」通道，避免切个条数闪一次骨架；仅筛选/搜索/状态/时间窗变更与首屏走骨架通道。

### 5.2 状态联动规则（给开发的唯一事实源）

| 触发 | page | 数据呈现 | total |
| --- | --- | --- | --- |
| 挂载首查 | 1 | 骨架 | 响应 total |
| 筛选/搜索/时间窗/状态/jobName/行业 变更 | **重置 1** | 骨架（新查询） | 按筛选后刷新（PRD 场景 2.1「共 N 条」N=筛选后条数） |
| 翻页（点页码/上一页/下一页） | 目标页 | 保留 + 在途 | 不变 |
| 条数切换 | **重置 1** | 保留 + 在途 | 不变（同结果集） |
| 翻页成功 | 目标页 | 整体替换 + 滚回列表顶 | 响应 total（以响应为准覆盖） |
| 翻页失败 | **回退显示当前页**（请求目标页仅存于重试闭包） | 保留当前页 | 不变 |
| 「清除筛选」CTA | 1 | 骨架 | 全量 total |

### 5.3 空页防御性回退（PRD 场景 2.2）

```
翻页/查询成功返回 items.length = 0 时：
  total = 0        → 空态渲染（分页条隐藏）
  total > 0 且 page > 1 → 页界漂移（浏览期间数据被删）→ 以 p' = ceil(total/pageSize)
                       静默自动重发一次（不提示用户），仍空 → 按空态渲染
显示层守卫：页码指示与按钮高亮始终以 min(page, ceil(total/pageSize)) 为准 clamp
```

### 5.4 在途竞态（PRD 场景 2.4，现状基线平移）

- 两页各保留单一 `listAbort: AbortController`（现状先例）：任何新请求发出前 abort 旧的，响应回填前检查 `signal.aborted`——筛选中止翻页、翻页中止翻页均覆盖。
- 分页条在途禁用防连点（§2.4）；筛选控件在途**不禁用**，变更即中止换道（响应快于禁用的体验取舍）。

### 5.5 回归不变项（T66 走查清单）

信息流无限滚动与兜底按钮、订阅页游标加载、两页详情列/401 跳登录/http 层错误映射、`PolicyDetail` 阅读埋点——全部不动。
