# 合规预检 · 21 财经 AI 条款（M15 T125 留档）

> 用途：REQ-20260926-12 拍板五-1 的「源级 AI 深度分析排除」承载落库前的开发预检留档（方案 §4.4 指定 T125 交付物）。
> 日期：2026-09-22 · 预检人：开发（T125）

## 1. 背景与问题

M14 批次一接入 21 财经（21jingji，channel/finance 编辑排序源）时留档：该站 robots.txt 为通配 `Allow`，但**显式禁止
GPTBot 等生成式 AI 训练爬虫**（见 ADR-0044 / T112 留档）。平台对资讯的 L2 深度分析（LLM 事件提取）属于「将抓取内容送入
第三方 LLM」的处理面，与「聚合展示」性质不同——需按 REQ 拍板五-1 做源级排除承载，两分支语义已由需求锁定：

- `L2`（深度分析排除）：条目照常采集/归类（L0/L1）/计热度资讯量，**不产事件、不进事件流**；
- `ALL`（全管道排除）：L0 即不建 `news_analysis` 行（不归类不分析；页面隐藏入口，变更控制专用）。

## 2. 预检结论

| 项 | 结论 |
| --- | --- |
| robots 原文复核 | 通配 Allow 覆盖普通抓取（聚合展示不涉）；对 `GPTBot`/`CCBot` 等 AI 训练 UA 显式 Disallow |
| 平台行为定性 | L1 归类/L2 事件提取把全文送 DeepSeek/GLM 推理——非训练但属「AI 深度处理」，按保守口径排除 |
| 承载落点 | `info_source.config.aiExclusion = "L2"`（方案 §3.4 config 字段裁决，ADR-0048 裁量 1；零 DDL） |
| 采集与展示 | 不受影响：SOURCE_POLL 轮询、资讯流、订阅推送照常（排除仅作用于 AI 管道消费面） |
| 归类与热度 | L1 照常归类；**热度资讯量照常计入**（REQ 拍板五-1 明确语义）；仅事件流/日报 topEvents 不含其事件 |
| 落库操作 | 源管理页 PATCH `config.aiExclusion`（NONE/L2/ALL 白名单，非法值 30072）；当前取值 **L2**，升 ALL 走变更控制 |

## 3. 落地核实清单（实现对照）

- `AiExclusion` 枚举（NONE/L2/ALL）+ `SourceConfig.aiExclusion` 字段 + `SourceConfigCodec`（NONE 不落键，存量
  JSON 字节级不变）。
- `AiExclusionResolver`：L2 段查询排除 L2+ALL 源；L0/L1 段排除 ALL 源（`findUnanalyzed`/`findPendingForL1` 下传）。
- 单测：排除源不进 L2 进 L1（`AiExclusionResolverTest`/`EventExtractionServiceTest`/`L0PrefilterServiceTest`/
  `NewsAnalysisRepositoryImplTest`）+ PATCH 非法值 30072 与徽章数据面回显（`InfoSourceControllerTest`/
  `SourceRegistryServiceIntegrationTest`）。
