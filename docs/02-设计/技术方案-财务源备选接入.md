## 🎯 1. 背景与目标

### 背景（设计前实测核实，2026-09-24）

1. 财务/公告是 `SourceProviders` 注册表中最后两个单 provider 源（FINANCE/ANNOUNCE 均仅 `eastmoney`）；2026-09-24 财务源 9501 事故期间无兜底（修复见 f3cdcc1），且 ISSUE-A 实证东财财务/公告两端口同日 WAF 收紧——东财系整体故障时两分区同裸奔。
2. 降级链模型（ADR-0033）与链执行器（`FallbackChainRunner`）已覆盖行情/估值/A 股列表三消费点，接入第二 provider = 「枚举登记 + 注册表补行 + adapter 消费点扩展 + 默认链自动生效」的复制推广。
3. 东财 datacenter 间歇变慢（本次实测 600519 首请求 3.28s、其余 ~0.1s），财务源 noRetry(2s) 尾部请求逼近超时线——备源接入是确定性收益。

### 目标（对齐 PRD，可量化）

- 财务源默认链 `[eastmoney, sina]`：东财失败或空响应（9501 错误体/`result:null` 等事故签名）自动降级新浪两页重拉整轮，恢复自动回归东财。
- 公告源默认链 `[eastmoney, cninfo]`（Should，源已调研合格，不走变更控制出口）：东财失败/空响应自动降级巨潮重拉。
- 兜底轮口径可信：最小完备集（报告期+营收+归母净利+ROE）与东财同报告期数值交叉核对，5/5 样本营收/净利相对偏差 0.0000%、ROE 偏差 0.00pp（附录 A），远优于需求门槛（≤1% / ≤0.5pp）。
- OK/MISSING/FAILED 三态契约与心跳签名不变；降级轮 WARN 留痕 + `RawFetch.source` 标注「东方财富财务→新浪备选」/「东方财富公告→巨潮资讯备选」。

### 验收红线逐条对齐

| PRD 验收点 | 方案承接 |
| --- | --- |
| 故事 1 场景 1~4（直用/降级/全链失败/回归） | §4.3 链执行消费点（第四/第五个，与 Quote/Valuation 同模式）；空响应触发条件覆盖 9501 错误体形态（`result:null` → `extractFirstRow` empty → 降级） |
| 故事 2 前端零改动 | `availableProviders` 来自注册表（ADR-0033 契约）；财务备选 `sina` 已在前端 `PROVIDER_LABELS` 映射内；公告备选 `cninfo` 为新 code，按需求许可补一条映射微调（§4.4，任务内完成） |
| 故事 3 最小完备集与容差 | §3.1 选型门槛 + 附录 A 容差表；缺失值沿映射白名单「缺失→不产出」语义 |
| 故事 4 公告备选（Should） | 巨潮 cninfo 调研合格（§3.2），**不走变更控制出口** |
| 故事 5 可观测 | `FallbackChainRunner` 既有 WARN 留痕 + 链位标注，零新增机制 |

### 非目标（防范围蔓延）

- 不做备选源历史财务序列（多报告期趋势）——主源即「最新报告期一条」，备选对齐现状。
- 不做港股财务备选专项（§3.1 实测：东财主源港股财务本身不可得，备选对齐主源现状）。
- 不做 NEWS/POLICY/EVENT 备选（无同族联动风险实证，需求 Won't）。

## ⚖️ 3. 候选源实测选型（2026-09-24，核心依据）

### 3.1 财务备选源：三候选实测对比 → **新浪（两页组合）合格入选**

| 候选 | 实测结论 | 证据要点 |
| --- | --- | --- |
| **腾讯** | ❌ 不合格（最小字段集缺失） | `qt.gtimg.cn/q=sh600519` 行情串仅 PE/PB/市值（39/52/46 位），无营收/净利/ROE；`web.ifzq.gtimg.cn`/`proxy.finance.qq.com` 的 F10 财务端点实测不存在（`Can't load controller:FinanceReportController` / `No dispatch info found`），社区亦无公开端点 |
| **网易** | ❌ 不合格（服务已下线） | `quotes.money.163.com/service/zycwzb_600519.html` 经典 CSV 接口与主站全站 **HTTP 502**（https/http、带/不带 UA+Referer 均同），服务整体下线 |
| **新浪** | ✅ **合格入选**（两页组合） | 见下 |

**新浪财务实测明细**（UA 仅普通浏览器串，无 Referer 要求）：

- **利润表页**：`https://money.finance.sina.com.cn/corp/go.php/vFD_ProfitStatement/stockid/{code}/ctrl/{year}/displaytype/4.phtml`（GBK HTML，表 id=`ProfitStatementNewTable0`）——提供「报表日期」（报告期口径，实测 2026-06-30/2026-03-31 按报告期列）、「一、营业总收入」或「一、营业收入」（银行/保险变体）、归母净利行（三种行名变体，§4.1）；**单位万元、含千分位逗号**。
- **财务指标页**：同路径 `vFD_FinancialGuideLine`（表 id=`BalanceSheetNewTable0`）——提供「加权净资产收益率(%)」（与东财 ROEJQ **数值完全一致**，勿用「净资产收益率(%)」摊薄口径 17.72）、「销售净利率(%)」（与 XSJLL 一致）、「销售毛利率(%)」（本批样本 '--' 缺失 → 降级不产出）。
- 旧财务摘要页 `vFD_FinanceSummary` 为空壳（HTML 注释「20180403 由于提供商数据不再更新，产品要求下线」），不可用；无可用 JSON 端点（`json_v2.php` 系 Service not found）。
- **限速友好**：`charset=gbk` 显式声明；空 UA 也 200；8 连发无间隔全 200 且稳定 ~0.17s，无 WAF 迹象；单标的按需两请求，礼貌抓取压力极小。
- **A 股覆盖**：沪/深/创业板（000001/600519/300750）、科创板（688111 实测）、银行/保险报表变体（000001/600036/601318）均可查；vFD 系 A 股页面，港股不可查（对齐主源现状，见下）。
- **主源港股核实（T55 沉淀项，提前完成）**：东财 F10 对港股 `SECURITY_CODE="00700"` 实测返回 `{"result":null,"success":false,"message":"返回数据为空","code":9201}`——**主源本身不覆盖港股财务**，备选不苛求（需求 §候选源验收要求 3 的既定口径）。
- **容差核对**：5 只样本（600519/000001/300750/600036/601318）与东财同报告期（2026-06-30）全字段核对，**营收/归母净利相对偏差 0.0000%、加权 ROE 与净利率偏差 0.00pp**（万元舍入量级 ~1e-7），完整表见附录 A。

**被否的组合细节**：单页只用 GuideLine（缺营收绝对值，不合格）；单页只用利润表（缺 ROE，不合格）——两页组合是新浪体系下唯一最小完备集拼法，两请求 ~0.4s 在财务源弹性预算内可承受。

### 3.2 公告备选源：巨潮资讯 cninfo 合格入选（Should 确认纳入，不走变更控制）

| 候选 | 实测结论 |
| --- | --- |
| **巨潮 cninfo** | ✅ **合格入选**，详见下 |
| 上交所/深交所官方接口 | 未采用（非不可用）：cninfo 单端点覆盖沪深全量（含 orgId 映射表），交易所官方则需按市场分端点分参数体系，接入面翻倍——按「无聊但成熟」原则取 cninfo |

**巨潮实测明细**：

- **orgId 映射**：`https://www.cninfo.com.cn/new/data/szse_stock.json`（GET，UTF-8 JSON，~592KB/6258 条）——文件名虽为 szse，实测**沪深全量皆在内**（600519→`gssh0600519`、000001→`gssz0000001`）；`sse_stock.json` 为 404，无需另拉。
- **公告查询**：`POST https://www.cninfo.com.cn/new/hisAnnouncement/query`（form：`pageNum=1&pageSize=3&column=szse&tabName=fulltext&stock={code},{orgId}&seDate=&isHLtitle=false`）——实测深沪样本均 200，按公告时间倒序；**orgId 必填**（缺省查询返回空）；无需 Referer/UA 要求（普通 UA 即可）；`isHLtitle=false` 得到无 `<em>` 高亮标签的干净标题。
- **字段映射可用**：`announcementId`（→externalId）、`announcementTitle`、`announcementTime`（epoch 毫秒，实测为公告日 00:00，600519 半年报 2026-08-15 与东财 `notice_date` 完全一致）、`adjunctUrl`（PDF 相对路径，拼 `https://static.cninfo.com.cn/` 前缀，实测 200 application/pdf）。
- **分类字段缺口**：cninfo 无东财 `column_name` 同款友好分类名（仅 `columnId` 数字串）——`category` 按白名单语义缺失不产出，公告分区核心形态（标题/时间/URL）与主源一致，符合故事 4 场景 1。
- **限速表现**：query 实测 0.17s~1.97s 波动（一次慢样本）；orgId 表拉取 ~0.3s。稳态单标的一次 query（orgId 表本地缓存 24h）；冷启动首轮两请求。礼貌抓取可行。

## 🔧 4. 详细设计（到类级，可直接开发）

### 4.1 新增 `SinaFinanceClient`（infrastructure/aggregation）

**职责**：按 6 位证券代码拉新浪 vFD 两页（利润表+财务指标），解析为**东财 F10 中间结构**（ADR-0031 模式：备选 client 输出主源键，下游映射零改动）。

**公开方法**：`Optional<Map<String, Object>> fetchFinance(String securityCode)`——返回即东财键 map；两页任一 HTTP 失败抛异常（由链执行器按该级失败处理），利润表空（当年/前年均无报告期行）返回 empty。

**URL 模板**（占位符运行时参数，沿 `announceDetailUrlTemplate` 先例，种子入 `DataSourceDefaults`）：

- `datasource.FINANCE.params.financeSinaProfitUrlTemplate` = `https://money.finance.sina.com.cn/corp/go.php/vFD_ProfitStatement/stockid/{code}/ctrl/{year}/displaytype/4.phtml`
- `datasource.FINANCE.params.financeSinaGuideUrlTemplate` = `.../vFD_FinancialGuideLine/stockid/{code}/ctrl/{year}/displaytype/4.phtml`

**处理链**：

1. **GBK**：读 `byte[]` 显式 GBK 解码（不依赖转换器对 `text/html; charset=gbk` 的行为，对齐 `TencentQuoteClient`/`GovPolicyClient` 先例），Jsoup 解析。
2. **表格导航**：按 id 定位（利润表 `ProfitStatementNewTable0` / 指标页 `BalanceSheetNewTable0`），行 → 单元格文本；「报表日期/报告日期」行为列头，**取第 1 数据列 = 最新报告期**（实测两页均倒序列）。
3. **年份回退**：`year = 当前年`；利润表无报告期行 → `year-1` 重拉一次；仍无 → empty。年初窗口（如 2027-01，年报未披露）由该回退自然取到 2026 报告期。
4. **行名匹配（实测变体清单）**：

   | 取值 | 行名变体（任一匹配即取） |
   | --- | --- |
   | 营收 | `一、营业总收入`（通用/创业板/科创板）/ `一、营业收入`（银行/保险/券商） |
   | 归母净利 | 正则 `^归属于母公司(所有者\|股东)?的净利润$`（三种实测变体：所有者/无/股东） |
   | ROE | `加权净资产收益率(%)`（与 ROEJQ 同「加权」口径；**禁用** `净资产收益率(%)` 摊薄口径） |
   | 净利率 | `销售净利率(%)` |
   | 毛利率 | `销售毛利率(%)`（金融股 '--' → 不产出） |

5. **数值转换**：剔千分位逗号 → BigDecimal（**万元 ×10000 → 元**，对齐东财 TOTALOPERATEREVE/PARENTNETPROFIT 元单位）；`--`/空/短行 → 该键不产出（缺失值防御，白名单语义）。
6. **输出键**（对齐 `field-mapping/eastmoney-finance.json` 既有映射，**该文件零改动**）：

   | 新浪来源 | 输出键（东财中间结构） | 转换 |
   | --- | --- | --- |
   | URL {code} | `SECURITY_CODE` | 原样 |
   | 营收行（万元） | `TOTALOPERATEREVE` | ×10000 → BigDecimal |
   | 归母净利行（万元） | `PARENTNETPROFIT` | ×10000 → BigDecimal |
   | 加权净资产收益率 | `ROEJQ` | BigDecimal |
   | 销售净利率 | `XSJLL` | BigDecimal |
   | 销售毛利率 | `XSMLL` | BigDecimal |
   | 报表日期 `yyyy-MM-dd` | `REPORT_DATE` | 补 ` 00:00:00`（对齐东财格式，`to_iso_date` 不变） |

7. **两页报告期一致性防御**：以利润表报告期列为准；指标页若最新列报告期不同（披露时点差），在指标页行内按「列头日期 == 利润表报告期」对位取值，找不到 → ROE 等比率键不产出（营收/净利/报告期仍产出）。

### 4.2 新增 `CninfoAnnounceClient`（infrastructure/aggregation）

**职责**：按 6 位证券代码拉巨潮最新 N 条公告，输出**东财公告 flat 中间结构**（`AnnounceSourceAdapter.flatten` 的同款键）。

**公开方法**：`Optional<List<Map<String, Object>>> fetchAnnouncements(String stockCode)`——条目 map 键见下表；`String detailUrlOf(String adjunctUrl)`——拼详情 PDF 直链。

**内部状态**：orgId 映射缓存——`volatile Map<String,String> codeToOrgId + volatile Instant loadedAt`，TTL 24h；过期/缺失时同步刷新（单飞：synchronized 双检），**刷新失败沿用旧表**（stale 容忍），无旧表可沿则抛异常（该级失败，交链执行器）；条目 ~6258 无内存压力。

**参数**（种子入 `DataSourceDefaults`，运行时可调）：`cninfoQueryUrl`（`https://www.cninfo.com.cn/new/hisAnnouncement/query`）、`cninfoStockListUrl`（`https://www.cninfo.com.cn/new/data/szse_stock.json`）、`cninfoDetailUrlPrefix`（`https://static.cninfo.com.cn/`）；条数复用既有 `announcePageSize`（默认 3）。

**字段映射**：

| cninfo 字段 | 输出键（东财 flat 结构） | 处理 |
| --- | --- | --- |
| `announcementId` | `art_code` | String 原样 |
| `announcementTitle` | `title` | isHLtitle=false 已免高亮标签；防御性再剔 `<em>` 类标签 |
| `announcementTime`（epoch ms） | `notice_date` | Asia/Shanghai 格式化 `yyyy-MM-dd HH:mm:ss`（`to_iso_date` 不变） |
| `secCode` / `secName` | `stock_code` / `short_name` | 原样 |
| `adjunctUrl` | `adjunct_url` | 仅供 adapter 拼 url，不进映射白名单 |
| （无对应字段） | `column_name` 缺失 | `category` 不产出（白名单语义） |

- 空响应：`announcements` null/[] → empty（→ 链下一级 / MISSING）；导航 `root.announcements[]` 与东财 `data.list[]` 的结构差异在 client 内吸收。
- POST form 契约常量：`column=szse`、`tabName=fulltext`、`isHLtitle=false`、`seDate=` 空（不限时间窗，默认时间倒序）。

### 4.3 链接入：注册表 + 两个消费点（第四/第五个）

**域层登记**（代码事实，新增 provider 先写接入代码的顺序不变）：

- `SourceProvider` 枚举新增成员：`CNINFO("cninfo", "巨潮资讯")`（`SINA` 既有复用）。
- `SourceProviders.PROVIDERS` 两行改写：`FINANCE → List.of(EASTMONEY, SINA)`、`ANNOUNCE → List.of(EASTMONEY, CNINFO)`——注册表全链即默认链（auto 语义），存量 DB 行无 `fallbackChain` 时自动按 `[eastmoney, sina]` / `[eastmoney, cninfo]` 生效，存量显式编排行不覆盖（`FallbackChains.resolve` 既有优先级）。

**`FinanceSourceAdapter` 改造**（对齐 `ValuationSourceAdapter` 逐条抄）：

- 新增构造参数 `SinaFinanceClient sinaClient`；常量 `CHAIN_CONFIG_KEY = "datasource.FINANCE.fallbackChain"`、`PROVIDERS = SourceProviders.providers(FINANCE)`、`SOURCE_NOUN = "财务"`。
- `doFetch` 改为 `FallbackChainRunner.fetch(SOURCE_NOUN, currentChain(), fetchByProvider)`；`fetchByProvider` switch：`EASTMONEY` 既有逻辑（label 替换链位标注）、`SINA` → `resolveSecurityCode` → `sinaClient.fetchFinance` → `RawFetch(data, label, now)`、其余抛 `IllegalArgumentException`（防御性快速失败）。
- `currentChain()` 抄 Valuation 版；**差异**：FINANCE 无旧 `backupSource` 单值键历史，legacy 恒传 null（Javadoc 注明）。
- 来源标注：链位 0「东方财富财务」/链位 1「东方财富财务→新浪备选」；强制 `["sina"]` 单源链时为「新浪财务」（`labelOf` 链位 0 以链首 provider 生成，自动成立）。

**`AnnounceSourceAdapter` 改造**（同模式，第五消费点）：

- 新增构造参数 `CninfoAnnounceClient cninfoClient`；`SOURCE_NOUN = "公告"`；`currentChain()` 同上（legacy 恒 null）。
- EASTMONEY 路径：既有 flatten + itemMapping + `client.detailUrlOf(art_code)` 逻辑不动（label 走链位标注）。
- CNINFO 路径：client 已输出 flat 条目 → 同一 `itemMapping`（`field-mapping/eastmoney-announce.json` **零改动**）逐条映射 → `item.put("url", cninfoClient.detailUrlOf(adjunct_url))` → `Map.of("items", ...)` 包装返回。

**装配**（`SourceAdapterRoutingConfig`）：`financeSourceAdapter`/`announceSourceAdapter` 两个 `@Bean` 方法签名各加一个 client 参数（bean 名单与路由 bean 调用处同步），无新增路由 bean。

**弹性/缓存/心跳语义（全部既有，零新增机制）**：

- 弹性预算两轮合用：FINANCE noRetry(2s) 覆盖「东财一轮 + 新浪两页」——东财快速失败形态（9501 空体/RST/HTTP 错误）实测 ~0.1s，新浪两页 ~0.4s，预算内完成；东财挂起至超时则兜底不保证（沿 ADR-0031 已知限制，接受留档）。ANNOUNCE 同理（巨潮稳态单请求；冷启动首轮 orgId 拉取 +0.3s，query 偶发 1.97s 慢样本同属该限制）。
- 缓存：备选轮产物入既有 `SourceCache`（FINANCE 1h / ANNOUNCE 300s），失败负缓存 30s 不变——故障期兜底数据被缓存，不放大备源限速压力。
- 心跳/三态：不改 `DataSourceEventRecorder` 公共签名；降级成功仍记 OK（detail "ok"），区分靠 `RawFetch.source` 标注 + WARN 日志（ADR-0031 从简口径）。
